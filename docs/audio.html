概要

NimaEngineのオーディオシステムは、XAudio2を基盤として、BGMと効果音の再生を管理します。

主な特徴

  • XAudio2による高品質な音声再生
  • カテゴリベースの音声管理
  • 複数のAudioインスタンスによる同時再生
  • ループ再生のサポート
  • リアルタイムなボリューム調整
  • WAV形式の完全サポート
  • パス検索機能による柔軟なファイル配置

対応フォーマット

  • WAV - 推奨フォーマット（非圧縮、低遅延）

アーキテクチャ

クラス構成

AudioManager

シングルトンクラス。音声ファイルの読み込み、Audioインスタンスの作成と管理を担当します。

Audio

個別の音声再生を制御するクラス。ループ再生、ボリューム調整などを行います。

SoundData

WAVファイルから読み込んだ音声データを保持する構造体。

データフロー

WAVファイル
    ↓
AudioManager::LoadWave()
    ↓
SoundData（メモリ上）
    ↓
AudioManager::GetNewAudio()
    ↓
Audio インスタンス
    ↓
Audio::Play()
    ↓
XAudio2 → スピーカー出力

AudioManager

オーディオシステム全体を管理するシングルトンクラス。

インスタンスの取得

auto audioManager = AudioManager::GetInstance();

主要メソッド

void Initialize()

XAudio2を初期化し、マスタリングボイスを作成します。フレームワークによって自動的に呼ばれます。

void Update()

オーディオシステムの状態を更新します（再生キューの処理など）。

void Finalize()

すべてのオーディオリソースを解放します。

void AddSearchPath(const std::string& path)

音声ファイルの検索パスを追加します。

Audio* GetNewAudio(const std::string& category, const std::string& filename)

新しいAudioインスタンスを作成して返します。ファイルが未読み込みの場合は自動的にロードされます。

GetNewAudio の詳細

パラメータ

  • category - カテゴリ名（"BGM", "Effect", "Voice" など）
  • filename - 音声ファイルのパス

戻り値

Audio* - 作成されたAudioインスタンスへのポインタ

動作

  1. 指定されたファイルがロード済みかチェック
  2. 未ロードの場合、WAVファイルを読み込む
  3. 新しいAudioインスタンスを作成
  4. 指定されたカテゴリに登録
  5. Audioポインタを返す

使用例

auto audioManager = AudioManager::GetInstance();

// BGMカテゴリで音声を取得
auto bgm = audioManager->GetNewAudio("BGM", "resources/audio/title.wav");

// Effectカテゴリで効果音を取得
auto shotSE = audioManager->GetNewAudio("Effect", "resources/audio/shot.wav");
auto jumpSE = audioManager->GetNewAudio("Effect", "resources/audio/jump.wav");

Audioクラス

個別の音声再生を制御するクラス。

※ Audio インスタンスは AudioManager::GetNewAudio() から取得します。生成・破棄は AudioManager が管理するため、手動の初期化・終了処理は不要です。

主要メソッド

void Play(bool isLoop = false)

音声を再生します。

  • isLoop - trueでループ再生
void Stop()

再生中の音声を停止します。

void SetVolume(float volume)

ボリュームを設定します。

  • volume - 0.0f（無音）～ 1.0f（最大音量）
float GetVolume() const

現在のボリュームを取得します。

使用例

// 音声の取得
auto bgm = audioManager->GetNewAudio("BGM", "title.wav");

// ループ再生
bgm->Play(true);

// ボリューム調整
bgm->SetVolume(0.7f); // 70%の音量

// 単発再生（効果音）
auto shotSE = audioManager->GetNewAudio("Effect", "shot.wav");
shotSE->Play(false); // ループなし

基本的な使い方

1. 初期化（自動）

オーディオシステムはNimaFrameworkによって自動的に初期化されます。

2. 音声ハンドルの取得

class Player
{
private:
    Audio* audioShot_ = nullptr;
    Audio* audioDeath_ = nullptr;
    
public:
    void Initialize()
    {
        auto audioManager = AudioManager::GetInstance();
        
        // 効果音を取得
        audioShot_ = audioManager->GetNewAudio("Effect", "resources/audio/shot.wav");
        audioDeath_ = audioManager->GetNewAudio("Effect", "resources/audio/death.wav");
        
        // ボリュームを設定
        audioShot_->SetVolume(0.8f);
    }
};

3. 再生

void Player::Shoot()
{
    // 弾を発射
    CreateBullet();
    
    // 効果音を再生
    audioShot_->Play();
}

void Player::OnDeath()
{
    // 死亡音を再生
    audioDeath_->Play();
}

カテゴリによる管理

カテゴリを使用することで、音声を論理的にグループ化できます。

推奨カテゴリ

  • "BGM" - バックグラウンドミュージック
  • "Effect" - 効果音（SE）
  • "Voice" - ボイス、ナレーション
  • "UI" - UIの効果音
  • "Ambient" - 環境音

カテゴリ別の管理例

class AudioController
{
private:
    std::vector<Audio*> bgmTracks_;
    std::vector<Audio*> effectSounds_;
    
public:
    void Initialize()
    {
        auto audioManager = AudioManager::GetInstance();
        
        // BGMの登録
        bgmTracks_.push_back(
            audioManager->GetNewAudio("BGM", "title.wav")
        );
        bgmTracks_.push_back(
            audioManager->GetNewAudio("BGM", "battle.wav")
        );
        
        // 効果音の登録
        effectSounds_.push_back(
            audioManager->GetNewAudio("Effect", "button.wav")
        );
        effectSounds_.push_back(
            audioManager->GetNewAudio("Effect", "explosion.wav")
        );
    }
    
    // カテゴリ全体のボリューム調整
    void SetBGMVolume(float volume)
    {
        for (auto& bgm : bgmTracks_)
        {
            bgm->SetVolume(volume);
        }
    }
    
    void SetEffectVolume(float volume)
    {
        for (auto& effect : effectSounds_)
        {
            effect->SetVolume(volume);
        }
    }
};

サンプルコード

BGMのフェードイン/フェードアウト

class BGMController
{
private:
    Audio* currentBGM_ = nullptr;
    float targetVolume_ = 1.0f;
    float currentVolume_ = 0.0f;
    float fadeSpeed_ = 0.5f; // 1秒でフェード完了
    
public:
    void PlayBGM(Audio* bgm, bool fadeIn = true)
    {
        currentBGM_ = bgm;
        
        if (fadeIn)
        {
            currentVolume_ = 0.0f;
            targetVolume_ = 1.0f;
        }
        else
        {
            currentVolume_ = 1.0f;
            targetVolume_ = 1.0f;
        }
        
        currentBGM_->SetVolume(currentVolume_);
        currentBGM_->Play(true); // ループ再生
    }
    
    void StopBGM(bool fadeOut = true)
    {
        if (fadeOut)
        {
            targetVolume_ = 0.0f;
        }
        else
        {
            if (currentBGM_)
            {
                // 即座に停止（XAudio2のStop実装が必要）
                currentVolume_ = 0.0f;
                currentBGM_->SetVolume(0.0f);
            }
        }
    }
    
    void Update(float deltaTime)
    {
        if (!currentBGM_) return;
        
        // フェード処理
        if (std::abs(currentVolume_ - targetVolume_) > 0.01f)
        {
            float step = fadeSpeed_ * deltaTime;
            
            if (currentVolume_ < targetVolume_)
            {
                currentVolume_ = std::min(currentVolume_ + step, targetVolume_);
            }
            else
            {
                currentVolume_ = std::max(currentVolume_ - step, targetVolume_);
            }
            
            currentBGM_->SetVolume(currentVolume_);
        }
    }
};

効果音の管理システム

class SoundEffectManager
{
private:
    std::unordered_map<std::string, Audio*> soundEffects_;
    
public:
    void Initialize()
    {
        auto audioManager = AudioManager::GetInstance();
        
        // 効果音を事前ロード
        RegisterSound("button", "resources/audio/button.wav");
        RegisterSound("explosion", "resources/audio/explosion.wav");
        RegisterSound("pickup", "resources/audio/pickup.wav");
        RegisterSound("jump", "resources/audio/jump.wav");
        RegisterSound("hit", "resources/audio/hit.wav");
    }
    
    void RegisterSound(const std::string& name, const std::string& filepath)
    {
        auto audioManager = AudioManager::GetInstance();
        soundEffects_[name] = audioManager->GetNewAudio("Effect", filepath);
    }
    
    void PlaySound(const std::string& name, float volume = 1.0f)
    {
        auto it = soundEffects_.find(name);
        if (it != soundEffects_.end())
        {
            it->second->SetVolume(volume);
            it->second->Play();
        }
    }
    
    // 距離減衰を考慮した3D音響
    void PlaySound3D(const std::string& name, 
                     const Vector3& soundPos, 
                     const Vector3& listenerPos,
                     float maxDistance = 50.0f)
    {
        auto it = soundEffects_.find(name);
        if (it == soundEffects_.end()) return;
        
        // 距離を計算
        float distance = (soundPos - listenerPos).Length();
        
        // 距離減衰を計算
        float attenuation = 1.0f - std::min(distance / maxDistance, 1.0f);
        attenuation = attenuation * attenuation; // 二次減衰
        
        // ボリュームを設定して再生
        it->second->SetVolume(attenuation);
        it->second->Play();
    }
};

シーン別BGM管理

class SceneBGMManager
{
private:
    std::unordered_map<std::string, Audio*> sceneBGMs_;
    Audio* currentBGM_ = nullptr;
    
public:
    void Initialize()
    {
        auto audioManager = AudioManager::GetInstance();
        
        // シーンごとのBGMを登録
        sceneBGMs_["Title"] = audioManager->GetNewAudio("BGM", "title.wav");
        sceneBGMs_["Game"] = audioManager->GetNewAudio("BGM", "game.wav");
        sceneBGMs_["Boss"] = audioManager->GetNewAudio("BGM", "boss.wav");
        sceneBGMs_["GameOver"] = audioManager->GetNewAudio("BGM", "gameover.wav");
        sceneBGMs_["Clear"] = audioManager->GetNewAudio("BGM", "clear.wav");
    }
    
    void PlaySceneBGM(const std::string& sceneName, float volume = 0.8f)
    {
        // 現在のBGMを停止
        if (currentBGM_)
        {
            currentBGM_->SetVolume(0.0f);
            // ※ 実際には停止処理が必要
        }
        
        // 新しいBGMを再生
        auto it = sceneBGMs_.find(sceneName);
        if (it != sceneBGMs_.end())
        {
            currentBGM_ = it->second;
            currentBGM_->SetVolume(volume);
            currentBGM_->Play(true); // ループ再生
        }
    }
    
    void StopCurrentBGM()
    {
        if (currentBGM_)
        {
            currentBGM_->SetVolume(0.0f);
            // ※ 実際には停止処理が必要
            currentBGM_ = nullptr;
        }
    }
};

Tips & ベストプラクティス

1. 事前ロードの推奨

頻繁に使用する音声は、シーンの初期化時に事前にロードしておくことで、再生時の遅延を防げます。

// 良い例：初期化時に取得
void GameScene::Initialize()
{
    audioExplosion_ = audioManager->GetNewAudio("Effect", "explosion.wav");
}

void GameScene::OnExplosion()
{
    audioExplosion_->Play(); // 即座に再生
}

2. ボリュームの適切な設定

  • BGM: 0.5～0.8（控えめに）
  • 効果音: 0.3～0.6（BGMより小さめ）
  • 重要な音: 0.7～1.0（明確に聞こえるように）

3. カテゴリの活用

設定画面でカテゴリごとのボリューム調整を実装する際に便利です。

4. メモリ管理

AudioインスタンスはAudioManagerが管理するため、手動でdeleteする必要はありません。

5. パスの管理

音声ファイルのパスは定数や設定ファイルで一元管理することを推奨します。

// 定数での管理
namespace Path::Audio
{
    constexpr const char* kSePlayerShoot = "resources/audio/shoot.wav";
    constexpr const char* kSePlayerDeath = "resources/audio/death.wav";
    constexpr const char* kBgmTitle = "resources/audio/bgm_title.wav";
}

6. 同時再生数の制限

同じ効果音が大量に同時再生されると音が割れる可能性があります。必要に応じて再生数を制限しましょう。

7. WAVファイルの最適化

  • サンプリングレート: 44.1kHz または 48kHz
  • ビット深度: 16bit（通常の効果音）、24bit（高音質BGM）
  • チャンネル: モノラル（効果音）、ステレオ（BGM）
