概要

NimaEngineの衝突判定システムは、効率的かつ柔軟な衝突検出を提供します。

主な特徴

  • 複数の形状タイプをサポート（AABB、OBB、Sphere）
  • ビットマスクによる衝突フィルタリング
  • コールバック関数による柔軟な衝突応答
  • Trigger（トリガー）とCollision（持続）の区別
  • 軽量化オプション（Cell-Based Filtering）
  • デバッグ可視化機能

サポートされる形状

  • Sphere（球） - 最速。シンプルな物体に最適
  • AABB（軸平行境界ボックス） - 高速。回転しない物体に最適
  • OBB（方向付き境界ボックス） - 回転する物体に対応

アーキテクチャ

クラス構成

CollisionManager

シングルトンクラス。すべてのコライダーを管理し、フレームごとに衝突判定を実行します。

Collider

個別の衝突判定オブジェクト。形状データ、属性、コールバックを持ちます。

Shape

衝突形状の列挙型（Sphere、AABB、OBB）。

AABB / OBB / Sphere

各形状のデータを保持する構造体。

衝突判定のフロー

フレーム開始
    ↓
CollisionManager::CheckAllCollision()
    ↓
すべてのコライダーペアをチェック
    ↓
[属性マスクフィルタリング]
    ↓（マスクが一致した場合のみ）
[軽量化フィルタリング（オプション）]
    ↓（範囲内の場合のみ）
[形状に応じた衝突判定]
    ↓（衝突している場合）
[Trigger判定]
    ↓
OnCollision / OnCollisionTrigger コールバック実行
    ↓

CollisionManager

衝突判定全体を管理するシングルトンクラス。

インスタンスの取得

auto collisionManager = CollisionManager::GetInstance();

主要メソッド

void Initialize()

衝突判定システムを初期化します。フレームワークによって自動的に呼ばれます。

void CheckAllCollision()

登録された全てのコライダーについて衝突判定を行います。毎フレーム呼ばれます。

void RegisterCollider(Collider* collider)

コライダーを登録します。

void DeleteCollider(Collider* collider)

コライダーを登録解除します。

void ClearCollider()

すべてのコライダー登録をクリアします。

uint32_t GetNewAttribute(std::string id)

新しい属性値（ビット）を発行します。

uint32_t* GetNewMask(std::string id, Args... ignoreNames)

指定IDに対して衝突無視対象を加味したマスクを生成・登録します。

使用例

// CollisionManagerの取得（DIコンテナから）
auto collisionManager = DIContainer::Resolve<CollisionManager>();

// または直接取得
auto collisionManager = CollisionManager::GetInstance();

// 属性の発行
uint32_t playerAttr = collisionManager->GetNewAttribute("player");
uint32_t enemyAttr = collisionManager->GetNewAttribute("enemy");

// マスクの発行（"player"は"player"自身と衝突しない）
uint32_t* playerMask = collisionManager->GetNewMask("player");

// マスクの発行（"enemy"は"enemy"と"bullet"を無視）
uint32_t* enemyMask = collisionManager->GetNewMask("enemy", "bullet");

Colliderクラス

個別の衝突判定オブジェクトを表すクラス。

コンストラクタ

Collider(bool enableDebugWindow = true)

主要メソッド

void SetColliderID(const std::string& id)

コライダーのIDを設定します（デバッグ用）。

void SetOwner(void* owner)

このコライダーを所有するオブジェクトを設定します。

void SetShape(Shape shape)

形状のタイプを設定します。

void SetShapeData(T* shapeData)

形状データ（AABB、OBB、Sphere）を設定します。

void SetAttribute(uint32_t attribute)

衝突属性（自分）を設定します。

void SetMask(uint32_t* mask)

衝突マスク（相手）を設定します。

void SetOnCollision(const std::function<void(const Collider*)>& func)

衝突時に呼ばれるコールバック関数を設定します（毎フレーム）。

void SetOnCollisionTrigger(const std::function<void(const Collider*)>& func)

衝突開始時に呼ばれるコールバック関数を設定します（1回のみ）。

void SetRadius(unsigned int rad)

軽量化フィルタリング用の半径を設定します。

void SetEnableLighter(bool flag)

軽量化フィルタリングを有効化します。

void SetEnable(bool flag)

このコライダーの有効/無効を切り替えます。

Getter

T* GetOwner() const

所有者オブジェクトを取得します。

AABB* GetAABB()

AABB形状データを取得します。

OBB* GetOBB()

OBB形状データを取得します。

Sphere* GetSphere()

Sphere形状データを取得します。

形状（Shape）

Sphere（球）

構造

struct Sphere
{
    Vector3 center; // 中心点
    float radius;   // 半径
};

特徴

  • 最も計算が高速
  • 回転に強い
  • 弾や球状の物体に最適

使用例

Sphere sphere;
sphere.center = Vector3(0, 0, 0);
sphere.radius = 1.0f;

collider->SetShape(Shape::Sphere);
collider->SetShapeData(&sphere);

AABB（軸平行境界ボックス）

構造

class AABB
{
    Vector3 min; // 最小座標
    Vector3 max; // 最大座標
};

特徴

  • 高速な判定
  • 軸に平行（回転しない）
  • 箱や部屋などの静的オブジェクトに最適

使用例

AABB aabb;
aabb.SetMinMax(Vector3(-1, -1, -1), Vector3(1, 1, 1));

collider->SetShape(Shape::AABB);
collider->SetShapeData(&aabb);

OBB（方向付き境界ボックス）

構造

class OBB
{
    Vector3 center;           // 中心点
    Vector3 orientations[3];  // 3軸の方向ベクトル
    Vector3 size;             // 各軸方向のサイズ
};

特徴

  • 任意の回転に対応
  • AABBより計算コストは高いが、より正確
  • 回転するキャラクターや乗り物に最適

使用例

OBB obb;
obb.SetCenter(Vector3(0, 0, 0));
obb.SetSize(Vector3(1, 1, 1));
// orientationsは自動的に設定される

collider->SetShape(Shape::OBB);
collider->SetShapeData(&obb);

属性とマスク

概念

属性（Attribute）とマスク（Mask）の組み合わせにより、どのコライダー同士が衝突するかを制御します。

仕組み

属性（Attribute）

自分自身の識別情報。32ビットの中の1ビットが立ちます。

player   = 0b00000001  (ビット0)
enemy    = 0b00000010  (ビット1)
bullet   = 0b00000100  (ビット2)
item     = 0b00001000  (ビット3)

マスク（Mask）

衝突したい相手のビットを立てます。

// プレイヤーのマスク（敵とアイテムと衝突）
playerMask = 0b00001010  (enemy | item)

// 敵のマスク（プレイヤーと弾と衝突）
enemyMask = 0b00000101  (player | bullet)

判定式

if ((colA.attribute & colB.mask) && (colB.attribute & colA.mask))
{
    // 衝突判定を実行
}

使用例

auto collisionManager = CollisionManager::GetInstance();

// 属性の発行
uint32_t playerAttr = collisionManager->GetNewAttribute("player");
uint32_t enemyAttr = collisionManager->GetNewAttribute("enemy");
uint32_t bulletAttr = collisionManager->GetNewAttribute("bullet");
uint32_t itemAttr = collisionManager->GetNewAttribute("item");

// プレイヤーのマスク（自分自身を除外、弾も除外）
uint32_t* playerMask = collisionManager->GetNewMask("player", "bullet");

// 敵のマスク（自分自身と他の敵を除外）
uint32_t* enemyMask = collisionManager->GetNewMask("enemy");

// 弾のマスク（敵のみと衝突）
uint32_t* bulletMask = collisionManager->GetNewMask("bullet", "player", "item");

// 設定
playerCollider->SetAttribute(playerAttr);
playerCollider->SetMask(playerMask);

enemyCollider->SetAttribute(enemyAttr);
enemyCollider->SetMask(enemyMask);

コールバック

OnCollision vs OnCollisionTrigger

OnCollision

衝突している間、毎フレーム呼ばれます。

  • 持続的なダメージ
  • 押し戻し処理
  • 接触中のエフェクト

OnCollisionTrigger

衝突開始時に1回だけ呼ばれます。

  • アイテム取得
  • 一度だけのダメージ
  • トリガーイベント

コールバック関数の設定

// OnCollision（毎フレーム）
collider->SetOnCollision([this](const Collider* other)
{
    // 毎フレーム呼ばれる処理
    std::cout << "Colliding with: " << other->GetColliderID() << std::endl;
});

// OnCollisionTrigger（1回のみ）
collider->SetOnCollisionTrigger([this](const Collider* other)
{
    // 衝突開始時に1回だけ呼ばれる
    std::cout << "Collision started with: " << other->GetColliderID() << std::endl;
});

// メンバ関数をバインド（推奨）
collider->SetOnCollision(
    std::bind(&Player::OnCollision, this, std::placeholders::_1)
);
collider->SetOnCollisionTrigger(
    std::bind(&Player::OnCollisionTrigger, this, std::placeholders::_1)
);

衝突相手の情報取得

void Player::OnCollision(const Collider* other)
{
    // 衝突相手の所有者を取得
    auto enemy = other->GetOwner<Enemy>();
    if (enemy)
    {
        // 敵との衝突処理
        TakeDamage(enemy->GetAttackPower());
    }
    
    auto item = other->GetOwner<Item>();
    if (item)
    {
        // アイテムとの衝突処理
        CollectItem(item);
    }
}

基本的な使い方

1. コライダーの作成

class Player
{
private:
    std::unique_ptr<Collider> collider_;
    OBB obb_;
    CollisionManager* collisionManager_;
};

2. 初期化

void Player::ColliderInitialize()
{
    collisionManager_ = DIContainer::Resolve<CollisionManager>();
    
    // コライダーの作成
    collider_ = std::make_unique<Collider>();
    
    // IDの設定
    collider_->SetColliderID("player");
    
    // 所有者の設定
    collider_->SetOwner(this);
    
    // 形状の設定
    collider_->SetShape(Shape::OBB);
    obb_.SetCenter(Vector3(0, 0, 0));
    obb_.SetSize(Vector3(0.5f, 0.5f, 0.5f));
    collider_->SetShapeData(&obb_);
    
    // 属性とマスクの設定
    collider_->SetAttribute(collisionManager_->GetNewAttribute("player"));
    collider_->SetMask(collisionManager_->GetNewMask("player"));
    
    // コールバックの設定
    collider_->SetOnCollision(
        std::bind(&Player::OnCollision, this, std::placeholders::_1)
    );
    collider_->SetOnCollisionTrigger(
        std::bind(&Player::OnCollisionTrigger, this, std::placeholders::_1)
    );
    
    // 軽量化の設定
    collider_->SetRadius(2u);
    collider_->SetEnableLighter(true);
    
    // コライダーの登録
    collisionManager_->RegisterCollider(collider_.get());
}

3. 更新

void Player::Update()
{
    // 形状データを更新
    obb_.SetCenter(position_);
    obb_.SetRotate(rotation_);
    
    // 軽量化用の位置も更新
    collider_->SetPosition(position_);
}

4. デストラクタでの登録解除

Player::~Player()
{
    // コライダーの登録解除
    if (collider_ && collisionManager_)
    {
        collisionManager_->DeleteCollider(collider_.get());
    }
}

サンプルコード

プレイヤーの衝突判定（Calms参照）

class Player
{
private:
    std::unique_ptr<Collider> collider_;
    OBB obb_;
    CollisionManager* collisionManager_;
    float health_ = 100.0f;
    
public:
    void ColliderInitialize()
    {
        collisionManager_ = DIContainer::Resolve<CollisionManager>();
        
        // コライダーの初期化
        collider_ = std::make_unique<Collider>();
        collider_->SetColliderID("player");
        collider_->SetAttribute(collisionManager_->GetNewAttribute("player"));
        collider_->SetOwner(this);
        collider_->SetShape(Shape::OBB);
        collider_->SetRadius(2u);
        collider_->SetMask(collisionManager_->GetNewMask("player"));
        collider_->SetOnCollision(
            std::bind(&Player::OnCollision, this, std::placeholders::_1)
        );
        collider_->SetOnCollisionTrigger(
            std::bind(&Player::OnCollisionTrigger, this, std::placeholders::_1)
        );
        collider_->SetEnableLighter(true);
        
        // コライダーの登録
        collisionManager_->RegisterCollider(collider_.get());
    }
    
    void OnCollision(const Collider* other)
    {
        // 毎フレーム呼ばれる（持続的な処理）
        auto enemy = other->GetOwner<Enemy>();
        if (enemy)
        {
            // 継続的なダメージ
            TakeDamage(0.1f);
        }
    }
    
    void OnCollisionTrigger(const Collider* other)
    {
        // 1回だけ呼ばれる（トリガー処理）
        auto item = other->GetOwner<Item>();
        if (item)
        {
            // アイテム取得
            CollectItem(item);
        }
        
        auto bullet = other->GetOwner<Bullet>();
        if (bullet)
        {
            // 被弾
            TakeDamage(bullet->GetDamage());
        }
    }
    
    void Update()
    {
        // 形状を更新
        obb_.SetCenter(position_);
        obb_.SetRotate(rotation_);
        obb_.SetSize(Vector3(0.5f, 0.5f, 0.5f));
        collider_->SetShapeData(&obb_);
        
        // 軽量化用
        collider_->SetPosition(position_);
    }
};

弾の衝突判定

class Bullet
{
private:
    std::unique_ptr<Collider> collider_;
    Sphere sphere_;
    CollisionManager* collisionManager_;
    bool isActive_ = true;
    float damage_ = 10.0f;
    
public:
    void Initialize()
    {
        collisionManager_ = DIContainer::Resolve<CollisionManager>();
        
        // 球形の衝突判定
        collider_ = std::make_unique<Collider>();
        collider_->SetColliderID("bullet");
        collider_->SetOwner(this);
        collider_->SetShape(Shape::Sphere);
        
        sphere_.center = position_;
        sphere_.radius = 0.2f;
        collider_->SetShapeData(&sphere_);
        
        // 敵とのみ衝突
        collider_->SetAttribute(collisionManager_->GetNewAttribute("bullet"));
        collider_->SetMask(collisionManager_->GetNewMask("bullet", "player", "item"));
        
        // トリガーのみ使用
        collider_->SetOnCollisionTrigger(
            std::bind(&Bullet::OnHit, this, std::placeholders::_1)
        );
        
        collisionManager_->RegisterCollider(collider_.get());
    }
    
    void OnHit(const Collider* other)
    {
        auto enemy = other->GetOwner<Enemy>();
        if (enemy)
        {
            // 敵にダメージを与える
            enemy->TakeDamage(damage_);
            
            // 弾を削除
            isActive_ = false;
        }
    }
    
    void Update()
    {
        if (!isActive_) return;
        
        // 弾を移動
        position_ += velocity_ * deltaTime;
        
        // 形状を更新
        sphere_.center = position_;
        collider_->SetShapeData(&sphere_);
    }
    
    ~Bullet()
    {
        if (collider_ && collisionManager_)
        {
            collisionManager_->DeleteCollider(collider_.get());
        }
    }
    
    float GetDamage() const { return damage_; }
};

アイテムの衝突判定

class Item
{
private:
    std::unique_ptr<Collider> collider_;
    Sphere sphere_;
    CollisionManager* collisionManager_;
    bool isCollected_ = false;
    ItemType type_;
    
public:
    void Initialize()
    {
        collisionManager_ = DIContainer::Resolve<CollisionManager>();
        
        collider_ = std::make_unique<Collider>();
        collider_->SetColliderID("item");
        collider_->SetOwner(this);
        collider_->SetShape(Shape::Sphere);
        
        sphere_.center = position_;
        sphere_.radius = 0.5f;
        collider_->SetShapeData(&sphere_);
        
        // プレイヤーとのみ衝突
        collider_->SetAttribute(collisionManager_->GetNewAttribute("item"));
        collider_->SetMask(collisionManager_->GetNewMask("item", "enemy", "bullet"));
        
        collider_->SetOnCollisionTrigger(
            std::bind(&Item::OnPickup, this, std::placeholders::_1)
        );
        
        collisionManager_->RegisterCollider(collider_.get());
    }
    
    void OnPickup(const Collider* other)
    {
        auto player = other->GetOwner<Player>();
        if (player && !isCollected_)
        {
            // プレイヤーに効果を適用
            player->ApplyItemEffect(type_);
            
            // アイテムを回収済みに
            isCollected_ = true;
            
            // コライダーを無効化
            collider_->SetEnable(false);
            
            // エフェクトや効果音を再生...
        }
    }
};

複雑なマスク設定の例

class GameInitializer
{
public:
    void SetupCollisionSystem()
    {
        auto collisionManager = CollisionManager::GetInstance();
        
        // 属性の発行
        uint32_t playerAttr   = collisionManager->GetNewAttribute("player");
        uint32_t enemyAttr    = collisionManager->GetNewAttribute("enemy");
        uint32_t pBulletAttr  = collisionManager->GetNewAttribute("player_bullet");
        uint32_t eBulletAttr  = collisionManager->GetNewAttribute("enemy_bullet");
        uint32_t itemAttr     = collisionManager->GetNewAttribute("item");
        uint32_t wallAttr     = collisionManager->GetNewAttribute("wall");
        
        // プレイヤー：敵、敵の弾、壁と衝突
        uint32_t* playerMask = collisionManager->GetNewMask(
            "player", "player_bullet", "item"
        );
        
        // 敵：プレイヤー、プレイヤーの弾、壁と衝突
        uint32_t* enemyMask = collisionManager->GetNewMask(
            "enemy", "enemy_bullet", "item"
        );
        
        // プレイヤーの弾：敵と壁のみと衝突
        uint32_t* pBulletMask = collisionManager->GetNewMask(
            "player_bullet", "player", "player_bullet", "item", "enemy_bullet"
        );
        
        // 敵の弾：プレイヤーと壁のみと衝突
        uint32_t* eBulletMask = collisionManager->GetNewMask(
            "enemy_bullet", "enemy", "enemy_bullet", "item", "player_bullet"
        );
        
        // アイテム：プレイヤーのみと衝突
        uint32_t* itemMask = collisionManager->GetNewMask(
            "item", "enemy", "player_bullet", "enemy_bullet", "wall"
        );
        
        // 壁：すべてと衝突
        uint32_t* wallMask = collisionManager->GetNewMask("wall");
    }
};

Tips & ベストプラクティス

1. 適切な形状の選択

  • Sphere：弾、球状の物体
  • AABB：静的な箱、壁、床
  • OBB：回転するキャラクター、車両

2. 軽量化の活用

// 遠くのオブジェクトとの衝突判定をスキップ
collider->SetRadius(10u);  // セル半径
collider->SetEnableLighter(true);

3. コールバックの使い分け

  • OnCollision：継続的なダメージ、押し戻し
  • OnCollisionTrigger：アイテム取得、単発ダメージ

4. デストラクタでの登録解除

オブジェクト削除時は必ずコライダーを登録解除しましょう。

~Player()
{
    if (collider_ && collisionManager_)
    {
        collisionManager_->DeleteCollider(collider_.get());
    }
}

5. 形状データの更新

オブジェクトが移動・回転したら、形状データを必ず更新してください。

6. 属性の管理

属性IDは定数で管理すると便利です。

namespace CollisionID
{
    constexpr const char* kPlayer = "player";
    constexpr const char* kEnemy = "enemy";
    constexpr const char* kBullet = "bullet";
}

7. デバッグ可視化

コライダーのコンストラクタでenableDebugWindow = trueにすると、デバッグウィンドウが表示されます。

8. パフォーマンス

  • 不要なコライダーはSetEnable(false)で無効化
  • 軽量化フィルタリングを活用
  • 適切なマスク設定で不要な判定を削減
