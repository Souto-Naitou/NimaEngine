概要

NimaEngineは、DirectX12を基盤とした高性能なゲームエンジンです。コンポーネントベースのアーキテクチャと依存性注入パターンを採用し、効率的なゲーム開発を実現します。

主な特徴

  • DirectX12ベースの高性能レンダリング
  • マルチスレッド対応のコマンドリスト管理
  • 柔軟なシーン管理システム
  • 充実したポストエフェクト
  • 統合されたデバッグツール（ImGui統合）
  • GLTFおよびOBJモデルのサポート
  • パーティクルシステム
  • 衝突判定システム
  • オーディオシステム（XAudio2）

アーキテクチャ

設計パターン

フレームワークパターン

すべてのアプリケーションはNimaFrameworkを継承し、Initialize()、Update()、Draw()、Finalize()をオーバーライドします。

シーンシステム

SceneBase派生クラスを使用し、SceneManagerとファクトリパターン（ISceneFactory）で管理されます。

依存性注入

DIContainerがサービスインスタンスを型ベースで登録・解決します。

オブジェクトシステム

グラフィックスオブジェクトはObjectSystemBaseMTを継承し、マルチスレッドのDirectX12コマンドリスト管理を実現します。

フレームワーク

NimaFramework

エンジンの中核となるフレームワーククラス。すべてのゲームアプリケーションはこのクラスを継承して実装します。

主要メソッド

void Run()

フレームワークのメインループを開始します。初期化、更新、描画、終了処理を順次実行します。

virtual void Initialize()

システムとサブシステムの初期化を行います。派生クラスでオーバーライドして独自の初期化処理を追加できます。

virtual void Update()

フレームごとの更新処理を行います。入力処理、シーン更新、物理演算などを実装します。

virtual void Draw()

フレームごとの描画処理を行います。レンダリングコマンドの発行と実行を管理します。

virtual void Finalize()

終了処理を行います。リソースの解放とクリーンアップを実行します。

void PreProcess()

描画前の共通前処理を行います。レンダーターゲットの設定などを実行します。

void PostProcess()

描画後の共通後処理を行います。フレーム表示とリソースのクリーンアップを実行します。

主要メンバ

DirectX12* pDirectX_

DirectX12の管理クラス

SceneManager* pSceneManager_

シーンの管理とライフサイクル制御

Input* pInput_

キーボード、マウス、ゲームパッド入力の管理

テクスチャの読み込みと管理

オーディオの再生と管理

ImGuiの統合とデバッグUIの管理を行います。

Logger

ログメッセージの記録とファイル出力を行います。

  • 階層的なログレベル（Info, Warning, Error）
  • JSON形式でのログ出力
  • タイムスタンプ付きログ

DebugManager

デバッグ機能の統合管理を行います。

EventTimer

イベントの処理時間を計測し、パフォーマンス分析を支援します。

サンプルコード

スプライトの表示

// スプライトの作成
auto sprite = std::make_unique<Sprite>();

// 初期化（テクスチャファイルパスを指定）
sprite->Initialize("resources/images/player.png");

// 位置とサイズの設定
sprite->SetPosition({100.0f, 100.0f});
sprite->SetSize({64.0f, 64.0f});

// アンカーポイント（中心点）の設定
sprite->SetAnchorPoint({0.5f, 0.5f}); // 中心を基準

// 色の設定（RGBA）
sprite->SetColor({1.0f, 1.0f, 1.0f, 1.0f});

// 回転（ラジアン）
sprite->SetRotation(0.0f);

// 更新
sprite->Update();

3Dモデルの読み込みと表示

// モデルローダーの作成（初期化時に1回だけ）
auto modelLoader = Helper::Model::CreateLoader<ModelLoaderAssimp>(pDirectX_.get());

// モデルストレージとマネージャの作成
auto modelStorage = Helper::Model::CreateStorage();
auto modelManager = Helper::Model::CreateManager(modelLoader.get(), modelStorage.get());

// モデルの読み込み
auto originalModel = modelManager->Load("resources/models/character.gltf");

// モデルのクローンを作成（複数インスタンス使用時）
auto clonedModel = originalModel->Cloned();

// Object3dを使用してモデルを表示
auto object = std::make_unique<Object3d>();
object->Initialize();
object->SetModel(clonedModel.get());

// トランスフォームの設定
object->SetTranslate(Vector3(0.0f, 0.0f, 5.0f));
object->SetRotate(Vector3(0.0f, 0.0f, 0.0f));
object->SetScale(Vector3(1.0f, 1.0f, 1.0f));

// ライティングの設定（オプション）
object->SetDirectionalLight(pDirectionalLight);
object->SetPointLight(pPointLight);

// 更新と描画
object->Update();
object->Draw1F();

入力処理

auto input = Input::GetInstance();

// キーボード入力（プレス状態）
if (input->PushKey(DIK_SPACE))
{
    // スペースキーが押されている
}

// キーボード入力（トリガー：押した瞬間のみ）
if (input->TriggerKey(DIK_SPACE))
{
    // スペースキーが押された瞬間
}

// 移動入力の例
auto dirX = input->PushKey(DIK_D) - input->PushKey(DIK_A);
auto dirZ = input->PushKey(DIK_W) - input->PushKey(DIK_S);

パーティクルエフェクト

// パーティクルストレージの取得
auto particleStorage = ParticleStorage::GetInstance();

// エミッタの作成
auto emitter = particleStorage->CreateEmitter();

// エミッタの初期化
emitter->Initialize();

// パラメータの設定
emitter->SetPosition(Vector3(0.0f, 5.0f, 0.0f));
emitter->SetCount(100); // 1回あたりのパーティクル数

// エミッタデータの設定（詳細パラメータ）
EmitterData emitterData;
emitterData.count = 10;
emitterData.frequency = 0.1f; // 0.1秒ごとに発生
emitterData.frequencyTime = 0.0f;
emitterData.translate = Vector3(0.0f, 0.0f, 0.0f);
emitterData.radius = 1.0f;
emitterData.emit = 1; // 発生を有効化
emitter->SetEmitterData(emitterData);

// 更新とエミット
emitter->Update();
emitter->Emit(); // パーティクルを発生させる

// 描画
emitter->Draw();

衝突判定

auto collisionManager = CollisionManager::GetInstance();

// コライダーの初期化（OBBの例）
OBB obb;
obb.Initialize();

// コライダーの作成と登録
auto collider = std::make_unique<Collider>();
collider->SetColliderID("player");
collider->SetAttribute(collisionManager->GetNewAttribute("player"));
collider->SetOwner(this); // オーナーオブジェクトへのポインタ
collider->SetShape(Shape::OBB);
collider->SetShapeData(&obb); // 形状データを設定
collider->SetRadius(2u); // 判定範囲の半径（セル分割用）
collider->SetMask(collisionManager->GetNewMask("player"));

// 衝突時のコールバックを設定
collider->SetOnCollision([this](Collider* other) {
    // 衝突時の処理
    Log("Collision with: " + other->GetColliderID());
});

// コライダーの登録
collisionManager->RegisterCollider(collider.get());

// 毎フレーム更新
obb.SetCenter(transform.translate);
obb.SetOrientations(rotateMatrix);
obb.SetSize(Vector3(0.5f, 0.5f, 0.5f));
collider->SetShapeData(&obb);

// 衝突判定の実行（通常はフレームワーク側で実行）
collisionManager->CheckAllCollision();
