概要

Inputクラスは、DirectInputを使用してキーボード、マウス、ゲームパッドの入力を統一的に管理するシングルトンクラスです。

主な特徴

  • DirectInput 8ベースの入力処理
  • キーボード、マウス、ゲームパッドの統合管理
  • プレス（継続）とトリガー（瞬間）の区別
  • ゲームパッドのデッドゾーン設定
  • ビューポートオフセットに対応したマウス座標
  • 入力の有効/無効の切り替え

インスタンスの取得

auto input = Input::GetInstance();

初期化

入力システムはNimaFrameworkによって自動的に初期化されます。手動で初期化する必要はありません。

// フレームワーク内で自動的に呼ばれる
input->Initialize(hInstance, hwnd);
input->Update(); // 毎フレーム自動更新

キーボード入力

PushKey / PushKeyC（プレス判定）

キーが押されている間、trueを返し続けます。

bool PushKey(BYTE keyNumber) const

DirectInputのキーコード（DIK_*）で判定します。

bool PushKeyC(char key) const

文字（'A', 'B', '1'など）で判定します。大文字で指定してください。

使用例

// DirectInputキーコードで判定
if (input->PushKey(DIK_SPACE)) {
    // スペースキーが押されている間、毎フレーム実行
    player->Jump();
}

// 文字で判定
if (input->PushKeyC('W')) {
    // Wキーが押されている間、前進
    player->MoveForward();
}

TriggerKey / TriggerKeyC（トリガー判定）

キーが押された瞬間のみtrueを返します。連打を防ぐのに有効です。

bool TriggerKey(BYTE keyNumber) const

DirectInputのキーコードでトリガー判定します。

bool TriggerKeyC(char key) const

文字でトリガー判定します。

使用例

// ジャンプは一度押したら一回だけ
if (input->TriggerKey(DIK_SPACE)) {
    player->Jump();
}

// アイテム使用も一回だけ
if (input->TriggerKeyC('E')) {
    player->UseItem();
}

主要なDirectInputキーコード

文字キー

DIK_A ~ DIK_Z

数字キー

DIK_1 ~ DIK_0

ファンクションキー

DIK_F1 ~ DIK_F12

移動キー（WASD）

  • DIK_W - W（前進/上）
  • DIK_A - A（左）
  • DIK_S - S（後退/下）
  • DIK_D - D（右）

矢印キー

  • DIK_UP - 上矢印
  • DIK_DOWN - 下矢印
  • DIK_LEFT - 左矢印
  • DIK_RIGHT - 右矢印

特殊キー

  • DIK_SPACE - スペース
  • DIK_RETURN - Enter
  • DIK_ESCAPE - Esc
  • DIK_LSHIFT / DIK_RSHIFT - Shift
  • DIK_LCONTROL / DIK_RCONTROL - Ctrl
  • DIK_LALT / DIK_RALT - Alt
  • DIK_TAB - Tab

マウス入力

MouseNum 列挙型

enum class MouseNum
  • Left - 左ボタン
  • Right - 右ボタン
  • Center - 中央ボタン（ホイールクリック）

PushMouse（マウスボタンプレス）

bool PushMouse(MouseNum mouseNum) const

指定されたマウスボタンが押されている間、trueを返します。

使用例

// 左クリックで連続射撃
if (input->PushMouse(Input::MouseNum::Left)) {
    player->Shoot();
}

// 右クリックでズーム
if (input->PushMouse(Input::MouseNum::Right)) {
    camera->Zoom(2.0f);
}

TriggerMouse（マウスボタントリガー）

bool TriggerMouse(MouseNum mouseNum) const

指定されたマウスボタンが押された瞬間のみtrueを返します。

使用例

// 左クリックで単発射撃
if (input->TriggerMouse(Input::MouseNum::Left)) {
    player->ShootOnce();
}

// 右クリックでアイテム選択
if (input->TriggerMouse(Input::MouseNum::Right)) {
    ui->OpenContextMenu();
}

GetCursorPosition（マウス座標）

POINT GetCursorPosition() const

マウスカーソルの現在位置を取得します。ビューポートオフセットが考慮されます。

使用例

POINT mousePos = input->GetCursorPosition();

// マウス位置にオブジェクトを配置
sprite->SetPosition(Vector2(
    static_cast<float>(mousePos.x),
    static_cast<float>(mousePos.y)
));

GetWheelDelta（マウスホイール）

int32_t GetWheelDelta() const

マウスホイールの回転量を取得します。正の値が上方向、負の値が下方向です。

使用例

int32_t wheelDelta = input->GetWheelDelta();

if (wheelDelta > 0) {
    // ホイールを上に回転：ズームイン
    camera->ZoomIn();
} else if (wheelDelta < 0) {
    // ホイールを下に回転：ズームアウト
    camera->ZoomOut();
}

ゲームパッド入力

アナログスティック

Vector2 GetLeftStickPosition() const

左アナログスティックの位置を取得します。範囲は-1.0～1.0です。

Vector2 GetRightStickPosition() const

右アナログスティックの位置を取得します。範囲は-1.0～1.0です。

使用例

// 左スティックで移動
Vector2 leftStick = input->GetLeftStickPosition();
if (leftStick.Length() > 0.1f) { // デッドゾーンチェック
    Vector3 moveDir(leftStick.x, 0.0f, leftStick.y);
    player->Move(moveDir);
}

// 右スティックでカメラ回転
Vector2 rightStick = input->GetRightStickPosition();
if (rightStick.Length() > 0.1f) {
    camera->Rotate(rightStick.x * sensitivity, rightStick.y * sensitivity);
}

デッドゾーン設定

void SetDeadZoneRange(float deadZoneRange)

スティックのデッドゾーン範囲を設定します。デフォルトは0.1f（10%）です。

使用例

// デッドゾーンを15%に設定
input->SetDeadZoneRange(0.15f);

※ ボタン入力については内部的にサポートされていますが、公開APIは実装に依存します。

主要メソッド

システム制御

void Enable(bool flag)

入力処理の有効/無効を切り替えます。メニュー表示時などに入力を無効化できます。

使用例

// ポーズメニューを開く時
void OpenPauseMenu()
{
    isPaused = true;
    input->Enable(false); // ゲーム内の入力を無効化
}

// ポーズメニューを閉じる時
void ClosePauseMenu()
{
    isPaused = false;
    input->Enable(true); // 入力を再度有効化
}

ビューポート設定

void SetWindowOffset(POINT offset)

ウィンドウのオフセットを設定します。

void SetWindowSize(SIZE size)

ウィンドウサイズを設定します。

サンプルコード

WASDキーで移動

void Player::UpdateMovement()
{
    auto input = Input::GetInstance();
    
    // 移動方向を計算
    int dirX = input->PushKey(DIK_D) - input->PushKey(DIK_A);
    int dirZ = input->PushKey(DIK_W) - input->PushKey(DIK_S);
    
    Vector3 moveDir(static_cast<float>(dirX), 0.0f, static_cast<float>(dirZ));
    
    // 正規化（斜め移動が速くならないように）
    if (moveDir.Length() > 0.0f) {
        moveDir = moveDir.Normalized();
        position += moveDir * moveSpeed * deltaTime;
    }
}

射撃システム

void Player::UpdateShooting()
{
    auto input = Input::GetInstance();
    
    // 連射（プレス判定）
    if (input->PushMouse(Input::MouseNum::Left))
    {
        // クールダウンチェック
        if (shotTimer.GetElapsedTime() > shotCooldown)
        {
            Shoot();
            shotTimer.Reset();
        }
    }
    
    // 特殊弾（トリガー判定）
    if (input->TriggerMouse(Input::MouseNum::Right))
    {
        if (specialAmmo > 0)
        {
            ShootSpecial();
            specialAmmo--;
        }
    }
}

スロー機能のトグル

void GameScene::UpdateSlowMotion()
{
    auto input = Input::GetInstance();
    
    // Shiftキーのトリガーでスローモーションのオン/オフを切り替え
    if (input->TriggerKey(DIK_LSHIFT))
    {
        isSlowMotion = !isSlowMotion;
        
        if (isSlowMotion)
        {
            pDeltaTimeManager_->SetTimeScale(0.3f);
            // エフェクトを有効化
            pViewport_->GetPostEffect<RadialBlur>()->Enable(true);
        }
        else
        {
            pDeltaTimeManager_->SetTimeScale(1.0f);
            // エフェクトを無効化
            pViewport_->GetPostEffect<RadialBlur>()->Enable(false);
        }
    }
}

マウスで照準

void Player::UpdateAiming()
{
    auto input = Input::GetInstance();
    
    // マウス位置を取得
    POINT mousePos = input->GetCursorPosition();
    
    // スクリーン座標をワールド座標に変換
    Vector3 worldPos = ScreenToWorld(
        Vector2(static_cast<float>(mousePos.x), static_cast<float>(mousePos.y))
    );
    
    // プレイヤーからマウス位置への方向を計算
    Vector3 aimDirection = (worldPos - playerPosition).Normalized();
    
    // 照準UIを更新
    crosshair->SetPosition(Vector2(
        static_cast<float>(mousePos.x),
        static_cast<float>(mousePos.y)
    ));
    
    // プレイヤーを回転
    float angle = std::atan2(aimDirection.x, aimDirection.z);
    playerRotation.y = angle;
}

ゲームパッドとキーボードの併用

void Player::UpdateInput()
{
    auto input = Input::GetInstance();
    Vector3 moveDir(0.0f, 0.0f, 0.0f);
    
    // ゲームパッド入力をチェック
    Vector2 leftStick = input->GetLeftStickPosition();
    if (leftStick.Length() > 0.1f)
    {
        // ゲームパッドで移動
        moveDir = Vector3(leftStick.x, 0.0f, leftStick.y);
    }
    else
    {
        // キーボードで移動（ゲームパッドが無い場合のフォールバック）
        int dirX = input->PushKey(DIK_D) - input->PushKey(DIK_A);
        int dirZ = input->PushKey(DIK_W) - input->PushKey(DIK_S);
        moveDir = Vector3(static_cast<float>(dirX), 0.0f, static_cast<float>(dirZ));
    }
    
    // 移動を適用
    if (moveDir.Length() > 0.0f)
    {
        moveDir = moveDir.Normalized();
        position += moveDir * moveSpeed * deltaTime;
    }
}

Tips & ベストプラクティス

1. プレスとトリガーの使い分け

  • Push系: 移動、射撃（連射）、ズームなど、継続的な動作
  • Trigger系: ジャンプ、アイテム使用、メニュー開閉など、一回だけの動作

2. 入力バッファリング

素早い入力を逃さないために、短時間の入力バッファを実装することを推奨します。

// ジャンプ入力を0.1秒間バッファリング
if (input->TriggerKey(DIK_SPACE))
{
    jumpBufferTimer = 0.1f;
}

jumpBufferTimer -= deltaTime;

if (jumpBufferTimer > 0.0f && player->IsGrounded())
{
    player->Jump();
    jumpBufferTimer = 0.0f;
}

3. デッドゾーンの適切な設定

コントローラーのドリフトを防ぐため、デッドゾーンを適切に設定しましょう。

// 推奨デッドゾーン: 10%～20%
input->SetDeadZoneRange(0.15f);

4. 入力の無効化を活用

カットシーンやメニュー表示時は入力を無効化することで、意図しない操作を防げます。

5. キー配置のカスタマイズ

将来的なキーコンフィグ実装を考慮して、キーコードを直接書くのではなく、定数や設定ファイルから読み込むようにしましょう。

// 良い例
const BYTE KEY_JUMP = DIK_SPACE;
if (input->TriggerKey(KEY_JUMP)) { ... }

// 悪い例
if (input->TriggerKey(DIK_SPACE)) { ... }
