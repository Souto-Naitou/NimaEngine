概要

NimaEngineのモデルシステムは、3Dモデルの読み込み、管理、描画、アニメーションをサポートします。

主な特徴

  • Assimpによる多様なフォーマット対応（GLTF/GLB、OBJ等）
  • GPU スキニングアニメーション
  • モデルのクローン機能（効率的なインスタンス生成）
  • テクスチャの動的な変更
  • 階層的なボーン構造のサポート
  • 遅延ローディングと非同期処理
  • パスリゾルバによる柔軟なファイル配置

対応フォーマット

  • GLTF 2.0 / GLB - 推奨フォーマット（アニメーション、PBRマテリアル）
  • OBJ - シンプルな静的メッシュ
  • FBX - Assimpを通じて読み込み可能

アーキテクチャ

クラス構成

ModelManager

モデルの読み込みと管理を統括。ローダーとストレージを制御します。

IModelLoader

モデルローダーのインターフェース。実装クラスにModelLoaderAssimpがあります。

ModelStorage

読み込まれたモデルデータをキャッシュして管理します。

IModel

モデルインターフェース。GltfModel、ObjModelなどが実装します。

GltfModel

GLTF形式のモデル。スケルトン、アニメーション、スキニングをサポート。

Animation

アニメーションデータとキーフレームを管理します。

Skeleton

骨格構造とジョイント階層を表現します。

SkinCluster

スキニング情報を保持し、頂点のボーン変形を制御します。

ModelManager

モデルの読み込みと管理を統括するクラス。

初期化

// NimaFrameworkによって自動的に初期化されます
// DIコンテナから取得
auto modelManager = DIContainer::Resolve<ModelManager>();

主要メソッド

void Initialize(IModelLoader* loader, ModelStorage* storage)

ローダーとストレージを渡してモデル管理を初期化します。

void AddSearchPath(const std::string& path)

モデルファイルの検索パスを追加します。

void AddLoadPath(const std::string& path)

事前ロードの対象パスを追加します。

int LoadAll()

登録済みのロードパスを全て読み込みます。

戻り値: 読み込んだ件数

IModel* Load(const std::string& path)

単一のモデルを読み込みます。既にロード済みの場合はキャッシュから返します。

戻り値: モデルのポインタ（失敗時は nullptr）

使用例

// DIコンテナから取得
auto modelManager = DIContainer::Resolve<ModelManager>();

// 検索パスを追加（初期化時）
modelManager->AddSearchPath("resources/models/");

// モデルをロード
auto playerModel = modelManager->Load("player.gltf");
auto enemyModel = modelManager->Load("enemy.glb");

IModelインターフェース

すべてのモデルクラスが実装する基底インターフェース。

主要メソッド

void Initialize()

モデルを初期化します。

void Update()

モデルの状態を更新します（アニメーション等）。

void Draw(ID3D12GraphicsCommandList* cl)

モデルを描画します。

std::unique_ptr<IModel> Cloned()

重要! モデルのクローンを作成します。元のモデルとは独立したインスタンスを返します。

void ChangeTexture(D3D12_GPU_DESCRIPTOR_HANDLE texSrvHnd)

テクスチャを動的に変更します。

bool IsEndLoading() const

モデルの読み込みが完了しているかを確認します。

ModelData* GetModelData()

モデルデータを取得します。

Cloned() の重要性

Cloned()メソッドは、同じモデルを複数のオブジェクトで使用する際に必須です。

なぜクローンが必要か?

  • 元のモデルはキャッシュされており、直接変更すべきではない
  • 各オブジェクトが独立したアニメーション状態を持つ必要がある
  • テクスチャやマテリアルを個別に変更できる
  • トランスフォームが独立している

クローンの仕組み

頂点バッファやインデックスバッファは共有され、アニメーション状態やマテリアルデータは独立します。これにより、メモリ効率と柔軟性を両立しています。

GltfModel

GLTF 2.0形式のモデルを扱うクラス。

特徴

  • スケルタルアニメーション対応
  • GPUスキニング
  • PBRマテリアル
  • 複数のテクスチャセット
  • 階層的なノード構造

固有メソッド

Animation* GetAnimationData()

アニメーションデータを取得します。

Skeleton* GetSkeleton()

スケルトンデータを取得します。

SkinCluster* GetSkinCluster()

スキンクラスターを取得します。

void DispatchSkinning()

スキニング計算をGPUに送信します。

アニメーションシステム

Animationクラス

キーフレームベースのアニメーションデータを管理します。

アニメーションの流れ

  1. GLTFファイルからアニメーションデータを読み込み
  2. 各ジョイントに対するキーフレーム（位置、回転、スケール）を保持
  3. Update()で現在の時間に基づいてキーフレーム間を補間
  4. Skeletonのローカル行列を更新
  5. スキニング行列を計算してGPUに送信
  6. GPUで頂点変形を実行

使用例

// アニメーション付きモデルの使用
auto characterModel = modelManager->Load("character.gltf");
auto instance = characterModel->Cloned();

// アニメーションの取得
auto animationData = static_cast<GltfModel*>(instance.get())->GetAnimationData();

// Update() でアニメーションが自動的に進行
instance->Update();

Skeleton & SkinCluster

Skeleton（骨格）

ボーンの階層構造とその変換行列を管理します。

  • ジョイント（ボーン）の階層を表現
  • 各ジョイントのローカル行列とグローバル行列を保持
  • アニメーションによってローカル行列が更新される

SkinCluster（スキンクラスター）

頂点とボーンの関連付けを管理します。

  • 各頂点がどのボーンに影響を受けるかを定義
  • ウェイト情報を保持
  • スキニング行列を計算してGPUに送信

スキニングの仕組み

// CPU側
for (各ジョイント)
{
    ジョイントのワールド行列を計算;
    スキニング行列 = 逆バインド行列 × ワールド行列;
}

// GPU側（コンピュートシェーダー）
for (各頂点)
{
    最終位置 = 0;
    for (影響を与える各ボーン)
    {
        最終位置 += (スキニング行列 × 元の位置) × ウェイト;
    }
}

基本的な使い方

1. モデルのロード

// ModelManagerの取得（DIコンテナから）
auto modelManager = DIContainer::Resolve<ModelManager>();

// モデルをロード（この時点ではキャッシュされたオリジナル）
auto originalModel = modelManager->Load("resources/models/player.gltf");

2. モデルのクローン

// クローンを作成（独立したインスタンス）
auto modelInstance = originalModel->Cloned();

3. Object3dに設定

// Object3dを作成
auto object = std::make_unique<Object3d>();
object->Initialize();

// モデルを設定
object->SetModel(modelInstance.get());

// トランスフォームを設定
object->SetTranslate(Vector3(0, 0, 0));
object->SetRotate(Vector3(0, 0, 0));
object->SetScale(Vector3(1, 1, 1));

4. 更新と描画

// 更新（アニメーションの進行）
object->Update();

// 描画はCanvasに登録して行う（初期化時に一度だけ登録すればよい）
// canvas->RegisterDrawable(object.get());

サンプルコード

プレイヤーモデルの初期化（Calms参照）

class Player
{
private:
    std::unique_ptr<IModel> pModelSelfBody_;
    std::unique_ptr<Object3d> object_;
    ModelManager* pModelManager_ = nullptr;
    
public:
    void Initialize()
    {
        // DIコンテナからModelManagerを取得
        pModelManager_ = DIContainer::Resolve<ModelManager>();
        
        // モデルの初期化
        ObjectsInitialize();
    }
    
    void ObjectsInitialize()
    {
        // オリジナルのモデルをロード
        auto originalModel = pModelManager_->Load(Path::Model::kPlayer);
        
        // クローンを作成（独立したインスタンス）
        pModelSelfBody_ = originalModel->Cloned();
        
        // Object3dの初期化
        object_ = std::make_unique<Object3d>();
        object_->Initialize();
        object_->SetName("player");
        
        // トランスフォームを設定
        object_->SetTranslate(Vector3(0, 0.5f, 0));
        object_->SetRotate(Vector3(0, 0, 0));
        
        // モデルを設定
        object_->SetModel(pModelSelfBody_.get());

        // マテリアルのカスタマイズ
        auto& option = object_->GetOption();
        option.materialData->environmentCoefficient = 0.0f;
        option.materialData->color = Vector4(0.0f, 1.0f, 0.0f, 1.0f);

        // 描画はCanvasに登録して行う
        // canvas->RegisterDrawable(object_.get());
    }

    void Update()
    {
        // オブジェクトの更新（アニメーション等）
        object_->Update();
    }
};

複数の敵キャラクターの生成

class EnemyManager
{
private:
    struct EnemyInstance
    {
        std::unique_ptr<IModel> model;
        std::unique_ptr<Object3d> object;
        Vector3 position;
        float health;
    };
    
    std::vector<EnemyInstance> enemies_;
    IModel* enemyModelOriginal_ = nullptr;
    ModelManager* modelManager_ = nullptr;
    
public:
    void Initialize()
    {
        modelManager_ = DIContainer::Resolve<ModelManager>();
        
        // 敵のオリジナルモデルをロード（1回だけ）
        enemyModelOriginal_ = modelManager_->Load("enemy.gltf");
    }
    
    void SpawnEnemy(const Vector3& position)
    {
        EnemyInstance enemy;
        
        // クローンを作成
        enemy.model = enemyModelOriginal_->Cloned();
        
        // Object3dを設定
        enemy.object = std::make_unique<Object3d>();
        enemy.object->Initialize();
        enemy.object->SetModel(enemy.model.get());
        enemy.object->SetTranslate(position);
        // 描画はCanvasに登録して行う
        // canvas->RegisterDrawable(enemy.object.get());

        enemy.position = position;
        enemy.health = 100.0f;
        
        // リストに追加
        enemies_.push_back(std::move(enemy));
    }
    
    void Update()
    {
        for (auto& enemy : enemies_)
        {
            enemy.object->Update();

            // 敵のAI処理など
            // ...
        }
    }
};

テクスチャの動的変更

class CharacterCustomizer
{
private:
    std::unique_ptr<IModel> characterModel_;
    std::vector<D3D12_GPU_DESCRIPTOR_HANDLE> skinTextures_;
    int currentSkinIndex_ = 0;
    
public:
    void Initialize()
    {
        auto modelManager = DIContainer::Resolve<ModelManager>();
        auto textureManager = DIContainer::Resolve<TextureManager>();
        
        // キャラクターモデルのロード
        auto original = modelManager->Load("character.gltf");
        characterModel_ = original->Cloned();
        
        // 複数のスキンテクスチャをロード
        skinTextures_.push_back(
            textureManager->GetSrvHandleGPU("skin_default.png")
        );
        skinTextures_.push_back(
            textureManager->GetSrvHandleGPU("skin_red.png")
        );
        skinTextures_.push_back(
            textureManager->GetSrvHandleGPU("skin_blue.png")
        );
    }
    
    void ChangeSkin(int skinIndex)
    {
        if (skinIndex >= 0 && skinIndex < skinTextures_.size())
        {
            currentSkinIndex_ = skinIndex;
            characterModel_->ChangeTexture(skinTextures_[skinIndex]);
        }
    }
    
    void NextSkin()
    {
        currentSkinIndex_ = (currentSkinIndex_ + 1) % skinTextures_.size();
        ChangeSkin(currentSkinIndex_);
    }
};

事前ロードシステム

class GameScene
{
private:
    ModelManager* modelManager_ = nullptr;
    bool isLoadingComplete_ = false;
    
public:
    void Initialize()
    {
        modelManager_ = DIContainer::Resolve<ModelManager>();
        
        // 検索パスを追加
        modelManager_->AddSearchPath("resources/models/");
        modelManager_->AddSearchPath("resources/models/characters/");
        modelManager_->AddSearchPath("resources/models/weapons/");
        
        // ロード対象を登録
        modelManager_->AddLoadPath("player.gltf");
        modelManager_->AddLoadPath("enemy_basic.gltf");
        modelManager_->AddLoadPath("enemy_boss.gltf");
        modelManager_->AddLoadPath("weapon_sword.gltf");
        modelManager_->AddLoadPath("weapon_gun.gltf");
        
        // 一括ロード（非同期）
        int loadedCount = modelManager_->LoadAll();
        
        std::cout << "Loaded " << loadedCount << " models." << std::endl;
    }
    
    void CheckLoadingStatus()
    {
        // 全てのモデルが読み込み完了しているか確認
        auto playerModel = modelManager_->Load("player.gltf");
        auto enemyModel = modelManager_->Load("enemy_basic.gltf");
        
        if (playerModel->IsEndLoading() && enemyModel->IsEndLoading())
        {
            isLoadingComplete_ = true;
        }
    }
};

Tips & ベストプラクティス

1. 必ずCloned()を使用する

ModelManager::Load()で返されたモデルを直接使用せず、必ずCloned()でコピーを作成してください。

// ❌ 悪い例：オリジナルを直接使用
auto model = modelManager->Load("player.gltf");
object->SetModel(model); // オリジナルを直接使用

// ✅ 良い例：クローンを作成
auto originalModel = modelManager->Load("player.gltf");
auto modelInstance = originalModel->Cloned();
object->SetModel(modelInstance.get());

2. パスの一元管理

モデルファイルのパスは定数で管理しましょう。

namespace Path::Model
{
    constexpr const char* kPlayer = "resources/models/player.gltf";
    constexpr const char* kEnemy = "resources/models/enemy.gltf";
    constexpr const char* kBoss = "resources/models/boss.gltf";
}

3. メモリ効率の考慮

  • 同じモデルを複数使う場合、Cloned()を使えば頂点データは共有される
  • アニメーション状態やマテリアルだけが独立するため、メモリ効率が良い

4. 読み込み完了の確認

非同期ロードの場合、IsEndLoading()で完了を確認してから使用しましょう。

5. GLTF形式の推奨

  • アニメーションが必要な場合はGLTF/GLBを使用
  • 静的メッシュのみならOBJも可
  • GLBはバイナリ形式でファイルサイズが小さい

6. スキニングのパフォーマンス

スキニングはGPUで実行されるため、大量のアニメーションキャラクターでも高速に動作します。

7. モデルデータの確認

auto modelData = model->GetModelData();
std::cout << "Vertex count: " << model->GetVertexCount() << std::endl;
std::cout << "Material name: " << modelData->material.name << std::endl;

8. テクスチャの事前ロード

モデルと一緒にテクスチャも事前にロードしておくことで、描画開始時の遅延を防げます。
