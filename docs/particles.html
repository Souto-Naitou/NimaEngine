概要

NimaEngineのパーティクルシステムは、爆発、煙、炎、魔法エフェクトなどの視覚効果を生成します。

主な特徴

  • GPUインスタンシングによる高速描画（最大256個同時表示）
  • JSON設定による柔軟なパーティクル定義
  • ビルボード（常にカメラを向く）対応
  • 物理シミュレーション（重力、摩擦、床衝突）
  • カラーグラデーション、スケールアニメーション
  • 手動モードと自動モードの切り替え
  • 3Dモデルベースのパーティクル

使用例

  • 爆発エフェクト
  • キャラクターの常時発生エフェクト（魔法オーラなど）
  • 環境パーティクル（雨、雪、火花）
  • ダメージエフェクト（血しぶき、破片）

アーキテクチャ

クラス構成

ParticleSystem

シングルトンクラス。パーティクルの共通描画処理を管理します。

Particle

パーティクルの描画と更新を担当。複数のパーティクルデータを保持します。

ParticleEmitter

パーティクルの発生を制御。JSON設定を読み込み、パーティクルを生成します。

EmitterData

エミッターの設定データ（発生数、速度、寿命など）を保持します。

ParticleData

個々のパーティクルの状態（位置、速度、寿命など）を保持します。

画面に描画

ParticleSystem

パーティクル描画の共通処理を管理するシングルトンクラス。

インスタンスの取得

auto particleSystem = ParticleSystem::GetInstance();

主要メソッド

void Initialize()

パーティクルシステムを初期化します。ルートシグネチャとパイプラインステートを作成します。

void DrawCall()

キューされた描画コマンドを発行します。

void SetGlobalEye(GameEye* pGameEye)

グローバルカメラを設定します。

定数

static constexpr uint32_t kMaxInstance_ = 256u

同時に描画できる最大インスタンス数。

使用例

// 通常、フレームワークによって自動的に初期化・描画されます
// 手動での操作は不要です

Particleクラス

パーティクルの描画と更新を担当するクラス。

主要メソッド

void Initialize(IModel* pModel)

パーティクルを初期化します。使用するモデルを設定します。

void Update()

すべてのパーティクルの状態を更新します（物理計算、寿命チェック）。

void DrawCall(ID3D12GraphicsCommandList* cl)

パーティクルを描画します。

void Finalize()

リソースを解放します。

void reserve(size_t size, bool isInit = false)

パーティクルデータのメモリを事前確保します。

void emplace_back(const ParticleData& data)

新しいパーティクルを追加します。

Setter

void SetEnableBillboard(bool enable)

ビルボード（常にカメラを向く）を有効/無効にします。

void SetGameEye(IGameEye** pGameEye)

カメラを設定します。

void SetName(const std::string& name)

デバッグ用の名前を設定します。

Getter

bool IsAbleDelete() const

全てのパーティクルが消滅し、削除可能かを返します。

ParticleEmitter

パーティクルの発生を制御するクラス。

初期化パラメータ

ParticleEmitter::Params（ParticleEmitter のネスト構造体）を使用します。

struct ParticleEmitter::Params
{
    Particle* particle = nullptr;  // 使用するParticleインスタンス
    std::string jsonPath = {};      // 設定JSONファイルのパス
};

主要メソッド

void Initialize(const ParticleEmitter::Params& params)

エミッターを初期化します。JSONファイルから設定を読み込みます。

void EnableManualMode()

手動発生モードを有効にします。Emit()を明示的に呼ぶ必要があります。

void DisableManualMode()

手動発生モードを無効にします。自動的に発生します。

void Update()

エミッターの状態を更新します。自動モードの場合、タイミングに応じて発生します。

void Draw1F()

パーティクルの描画を行います（内部でParticle::DrawCall()を呼びます）。

void Emit()

1回分のパーティクル発生を行います。手動モードで使用します。

void Finalize()

リソースを解放します。

Setter

void SetPosition(const Vector3& position)

エミッターの位置を設定します。

void SetEnableBillboard(bool enable)

ビルボードを有効/無効にします。

使用例

// エミッターの作成
ParticleEmitter::Params emitterParams = {};
emitterParams.particle = particleInstance;
emitterParams.jsonPath = "resources/json/particles/explosion.json";

auto emitter = std::make_unique<ParticleEmitter>();
emitter->Initialize(emitterParams);
emitter->SetEnableBillboard(true);

// 手動モード
emitter->EnableManualMode();

// 更新ループ
emitter->Update();

// 必要なタイミングで発生
if (explosionTriggered)
{
    emitter->Emit();
}

// 描画
emitter->Draw1F();

EmitterData（JSON）

JSON設定ファイル

パーティクルの挙動はJSONファイルで設定します。

※ JSONは EmitterData（Type::ParticleEmitter::v3::Data）のシリアライズ形式です。通常はエンジン内のImGuiエディタで編集・保存し、開発中はホットリロードされます。以下は実際のキー構造です（ranges 内の各項目は Range 型で、始点・終点を持ちます）。

主要パラメータ（キー構造）

common（共通）

  • emitInterval - 発生間隔（秒）
  • emitNum - 1回あたりの発生数
  • emitterLifeTime - エミッタの寿命（秒）
  • particleLifeTime - パーティクルの寿命（秒）
  • scaleFixed / scaleDelayTime - 固定スケール / スケール遅延
  • emitPositionFixed - 固定発生位置
  • alphaDeltaValue - 透明度の変化量
  • velocityFixed - 固定速度

ranges（範囲・始点終点）

  • scale / scaleRandom - スケール範囲 / ランダム範囲
  • position - 発生位置範囲
  • color - 色変化（始点→終点）
  • velocityRandom / velocityRandomSphere - 速度ランダム範囲
  • rotationRandom - 回転ランダム範囲

physics（物理）

  • gravity - 重力
  • resistance - 抵抗
  • frictionCoef - 摩擦係数
  • smoothNoisePower - スムースノイズ強度

flags（フラグ）

  • enableRandomVelocity / enableRandomEmit / enableRandomRotation / enableRandomScale
  • enableScaleTransition - スケール遷移
  • enableCollisionFloor - 床衝突の有効/無効
  • enableSmoothNoise - スムースノイズ
  • velocityDistribution - 速度分布（0: Box, 1: Sphere）

collisionFloor（床衝突）

  • elevation - 床の高さ
  • bouncePower - 反発係数

JSON設定例（構造）

{
    "version": 3,
    "name": "explosion",
    "common": {
        "emitInterval": 0.1,
        "emitNum": 50,
        "emitterLifeTime": 2.0,
        "particleLifeTime": 1.0,
        "scaleFixed": { "x": 1.0, "y": 1.0, "z": 1.0 },
        "scaleDelayTime": 0.0,
        "emitPositionFixed": { "x": 0.0, "y": 0.0, "z": 0.0 },
        "alphaDeltaValue": 0.02,
        "velocityFixed": { "x": 0.0, "y": 0.0, "z": 0.0 }
    },
    "ranges": {
        "scale":          { /* Range<Vector3> 始点/終点 */ },
        "scaleRandom":    { /* Range<Vector3> */ },
        "position":       { /* Range<Vector3> */ },
        "color":          { /* Range<Vector4> */ },
        "velocityRandom": { /* Range<Vector3> */ },
        "rotationRandom": { /* Range<Vector3> */ },
        "velocityRandomSphere": { /* Range<float> */ }
    },
    "physics": {
        "gravity":     { "x": 0.0, "y": -9.8, "z": 0.0 },
        "resistance":  { "x": 0.0, "y": 0.0, "z": 0.0 },
        "frictionCoef": 0.95,
        "smoothNoisePower": 0.1
    },
    "flags": {
        "enableRandomVelocity": true,
        "enableRandomEmit": false,
        "enableRandomRotation": false,
        "enableRandomScale": false,
        "enableScaleTransition": true,
        "enableCollisionFloor": true,
        "enableSmoothNoise": false,
        "velocityDistribution": 0
    },
    "collisionFloor": {
        "elevation": 0.0,
        "bouncePower": 0.4
    }
}

基本的な使い方

1. Particleの作成（ParticleStorageから取得）

// Particleインスタンスを生成（ParticleStorageが所有・管理する）
Particle* particle = ParticleStorage::GetInstance()->CreateParticle();

2. ParticleEmitterの初期化

class Player
{
private:
    std::unique_ptr<ParticleEmitter> emitterConstant_;
    Particle* particle_;
    
public:
    void ParticleEmittersInitialize()
    {
        // 初期化パラメータの設定
        ParticleEmitter::Params emitterParams = {};
        emitterParams.particle = particle_;
        emitterParams.jsonPath = "resources/json/particles/PlayerConstant.json";
        
        // エミッターの作成と初期化
        emitterConstant_ = std::make_unique<ParticleEmitter>();
        emitterConstant_->Initialize(emitterParams);
        
        // 手動モードを有効化
        emitterConstant_->EnableManualMode();
        
        // ビルボードを有効化
        emitterConstant_->SetEnableBillboard(true);
    }
};

3. 更新と発生

void Player::Update()
{
    // エミッターの位置を更新
    emitterConstant_->SetPosition(position_);
    
    // エミッターの更新
    emitterConstant_->Update();
    
    // 必要なタイミングで発生
    if (shouldEmit)
    {
        emitterConstant_->Emit();
    }
}

4. 描画

void Player::Draw()
{
    // エミッターの描画
    emitterConstant_->Draw1F();
}

5. 終了処理

void Player::Finalize()
{
    // エミッターの解放
    if (emitterConstant_)
    {
        emitterConstant_->Finalize();
    }
}

サンプルコード

プレイヤーの常時エフェクト（Calms参照）

class Player
{
private:
    std::unique_ptr<ParticleEmitter> emitterConstant_;
    Particle* particle_;
    Vector3 position_;
    
public:
    void ParticleEmittersInitialize()
    {
        // 初期化パラメータの設定
        ParticleEmitter::Params emitterParams = {};
        emitterParams.particle = particle_;
        emitterParams.jsonPath = "resources/json/particles/PlayerConstant.json";
        
        // エミッターの作成
        emitterConstant_ = std::make_unique<ParticleEmitter>();
        emitterConstant_->Initialize(emitterParams);
        
        // 手動モードを有効化（任意のタイミングで発生）
        emitterConstant_->EnableManualMode();
        
        // ビルボードを有効化（常にカメラを向く）
        emitterConstant_->SetEnableBillboard(true);
    }
    
    void Update()
    {
        // エミッターの位置を更新
        emitterConstant_->SetPosition(position_);
        
        // エミッターの更新
        emitterConstant_->Update();
        
        // 毎フレーム発生
        emitterConstant_->Emit();
    }
    
    void DrawLine()
    {
        // パーティクルの描画
        emitterConstant_->Draw1F();
    }
};

爆発エフェクト

class Explosion
{
private:
    std::unique_ptr<ParticleEmitter> emitter_;
    Particle* particle_;
    Vector3 position_;
    bool hasEmitted_ = false;
    
public:
    void Initialize(Particle* particle, const Vector3& position)
    {
        particle_ = particle;
        position_ = position;
        
        // 爆発用のJSON設定
        ParticleEmitter::Params params = {};
        params.particle = particle_;
        params.jsonPath = "resources/json/particles/explosion.json";
        
        emitter_ = std::make_unique<ParticleEmitter>();
        emitter_->Initialize(params);
        
        // 手動モード（1回だけ発生）
        emitter_->EnableManualMode();
        emitter_->SetEnableBillboard(true);
        emitter_->SetPosition(position_);
    }
    
    void Update()
    {
        if (!hasEmitted_)
        {
            // 最初のフレームで1回だけ発生
            emitter_->Emit();
            hasEmitted_ = true;
        }
        
        emitter_->Update();
    }
    
    void Draw()
    {
        emitter_->Draw1F();
    }
    
    bool IsFinished() const
    {
        // すべてのパーティクルが消滅したか
        return particle_->IsAbleDelete();
    }
};

ダメージエフェクト（血しぶき）

class Enemy
{
private:
    std::unique_ptr<ParticleEmitter> pParticleDeathShort_;
    std::unique_ptr<ParticleEmitter> pParticleDeathSplatter_;
    Particle* particle_;
    
public:
    void InitializeParticleEmitters()
    {
        // 短いパーティクル（火花）
        ParticleEmitter::Params params;
        params.particle = particle_;
        params.jsonPath = "resources/json/particles/EnemyDeathShort.json";
        
        pParticleDeathShort_ = std::make_unique<ParticleEmitter>();
        pParticleDeathShort_->Initialize(params);
        pParticleDeathShort_->EnableManualMode();
        pParticleDeathShort_->SetEnableBillboard(false); // 3D回転
        
        // 飛び散るパーティクル（血液）
        params.jsonPath = "resources/json/particles/EnemyDeathSplatter.json";
        pParticleDeathSplatter_ = std::make_unique<ParticleEmitter>();
        pParticleDeathSplatter_->Initialize(params);
        pParticleDeathSplatter_->EnableManualMode();
        pParticleDeathSplatter_->SetEnableBillboard(false);
    }
    
    void OnDeath()
    {
        // 死亡時にパーティクルを発生
        pParticleDeathShort_->SetPosition(position_);
        pParticleDeathShort_->Emit();
        
        pParticleDeathSplatter_->SetPosition(position_);
        pParticleDeathSplatter_->Emit();
    }
    
    void Update()
    {
        pParticleDeathShort_->Update();
        pParticleDeathSplatter_->Update();
    }
    
    void Draw()
    {
        pParticleDeathShort_->Draw1F();
        pParticleDeathSplatter_->Draw1F();
    }
};

連続発生（自動モード）

class Torch
{
private:
    std::unique_ptr<ParticleEmitter> fireEmitter_;
    Particle* particle_;
    Vector3 position_;
    
public:
    void Initialize()
    {
        // 炎のパーティクル

        params.particle = particle_;
        params.jsonPath = "resources/json/particles/fire.json";
        
        fireEmitter_ = std::make_unique<ParticleEmitter>();
        fireEmitter_->Initialize(params);
        
        // 自動モード（JSON設定の間隔で自動発生）
        fireEmitter_->DisableManualMode();
        fireEmitter_->SetEnableBillboard(true);
        fireEmitter_->SetPosition(position_);
    }
    
    void Update()
    {
        // 自動モードなので、Update()内で自動的に発生
        fireEmitter_->Update();
    }
    
    void Draw()
    {
        fireEmitter_->Draw1F();
    }
};

複数エミッターの組み合わせ

class GameClearAnimation
{
private:
    std::unique_ptr<ParticleEmitter> pEmitter_;
    Particle* particle_;
    TimeMeasurer timer_;
    
public:
    void Initialize(Particle* particle)
    {
        particle_ = particle;
        
        // クリアエフェクト用JSON
        ParticleEmitter::Params emitterParams = {};
        emitterParams.particle = particle_;
        emitterParams.jsonPath = "resources/json/particles/GameClearEffect.json";
        
        pEmitter_ = std::make_unique<ParticleEmitter>();
        pEmitter_->Initialize(emitterParams);
        pEmitter_->EnableManualMode();
        pEmitter_->SetEnableBillboard(true);
        pEmitter_->SetPosition(Vector3(0, 2, 0));
        
        timer_.Start();
    }
    
    void Update()
    {
        float time = timer_.GetNow<float>();
        
        // 一定間隔で発生
        if (static_cast<int>(time * 10) % 2 == 0)
        {
            pEmitter_->Emit();
        }
        
        pEmitter_->Update();
    }
    
    void Draw()
    {
        pEmitter_->Draw1F();
    }
};

Tips & ベストプラクティス

1. 手動モードvs自動モード

  • 手動モード：爆発、ダメージエフェクトなど、特定タイミングで発生
  • 自動モード：炎、煙など、連続的に発生

2. ビルボードの使い分け

  • 有効：炎、煙、魔法エフェクトなど平面的な表現
  • 無効：破片、火花など3D的な回転が必要

3. JSON設定のチューニング

// 爆発エフェクトの例（common / physics / collisionFloor に設定）
{
    "common": {
        "emitNum": 100,             // 多めに発生
        "particleLifeTime": 0.6     // 短めの寿命
    },
    "physics": {
        "gravity": { "x": 0.0, "y": -20.0, "z": 0.0 }  // 強い重力
    },
    "collisionFloor": { "bouncePower": 0.2 }           // 低い反発
}

4. パフォーマンス

  • 同時発生数を256個以下に制限
  • 寿命を適切に設定（長すぎると描画負荷増）
  • 不要なエミッターはFinalize()で解放

5. reserve()の活用

// 大量のパーティクルを扱う場合、事前にメモリ確保
particle->reserve(6000, true);

6. JSON設定のホットリロード

開発中は、JSON設定を変更すると自動的にリロードされます（reloadInterval_設定による）。

7. 色のグラデーション

// 炎の例：オレンジ → 黒（ranges.color の始点→終点で指定）
"ranges": {
    "color": { /* 始点 (1.0, 0.5, 0.0, 1.0) → 終点 (0.1, 0.1, 0.1, 0.0) */ }
}

8. 床衝突の活用

// 床で跳ね返るパーティクル
"flags":   { "enableCollisionFloor": true },
"collisionFloor": {
    "elevation": 0.0,     // 床の高さ
    "bouncePower": 0.6    // 反発係数
},
"physics": { "frictionCoef": 0.9 }   // 摩擦係数
