概要

ポストエフェクトは、レンダリング済みの画像に対して適用される画面全体のエフェクトです。NimaEngineでは、複数のポストエフェクトを組み合わせて使用できます。

主な特徴

  • DirectX12のコンピュートシェーダーを活用した高速処理
  • 複数のエフェクトをチェーン可能
  • リアルタイムでのパラメータ調整
  • リソース状態の自動管理
  • ウィンドウリサイズへの自動対応

処理フロー

シーン描画 → PostEffect 1 → PostEffect 2 → ... → 最終出力

IPostEffect インターフェース

すべてのポストエフェクトはIPostEffectインターフェースを実装しています。

主要メソッド

void Initialize(const PostEffectInitParams& desc)

エフェクトを初期化し、必要なリソースを確保します。

void Finalize()

リソースを解放します。

void Enable(bool flag)

エフェクトの有効/無効を設定します。

bool Enabled() const

エフェクトが有効かどうかを返します。

void Apply()

エフェクトを適用します。コマンドリストにGPU命令を記録します。

void Setting()

描画のための設定を行います。ディスクリプタやリソースの準備を実施します。

void SetInputTextureHandle(D3D12_GPU_DESCRIPTOR_HANDLE gpuHandle)

入力テクスチャのGPUハンドルを設定します。

D3D12_GPU_DESCRIPTOR_HANDLE GetOutputTextureHandle() const

出力テクスチャのGPUハンドルを取得します。

DX12Resource* GetOutputResource() const

適用後のリソースを取得します。

基本的な使い方

ポストエフェクトは Canvasごと に管理されます。Canvas::GetPostEffectExecutor() が返す PostEffectExecutor に、PostEffectClassName 列挙型で指定したエフェクトを追加します。

1. エフェクトの追加と有効化

// Canvasのポストエフェクト実行器にエフェクトを追加する
// AddEffect は基底 IPostEffect* を返す
IPostEffect* bloom = canvas->GetPostEffectExecutor().AddEffect(
    PostEffectClassName::GaussianBloom
);

// エフェクトを有効化
bloom->Enable(true);

2. パラメータの調整

// 個別パラメータは基底 IPostEffect* には無いため、
// 具象クラスへキャストするか、デバッグUI（ImGui）から調整します。
auto* concrete = static_cast<GaussianBloom*>(bloom);
// concrete->... // 具象クラスが公開するSetter/オプションを使用

// 有効/無効の切り替えと状態取得は基底インターフェースで可能
bloom->Enable(true);
bool isOn = bloom->Enabled();

3. 複数のエフェクトの組み合わせ

// 複数のエフェクトを追加（登録順に適用されます）
auto& executor = canvas->GetPostEffectExecutor();
executor.AddEffect(PostEffectClassName::GaussianBloom)->Enable(true);
executor.AddEffect(PostEffectClassName::DepthBasedOutline)->Enable(true);
executor.AddEffect(PostEffectClassName::RadialBlur)->Enable(true);

利用可能なエフェクト

GaussianBloom（ガウシアンブルーム）

明るい領域を発光させるエフェクト。光源や反射を強調し、幻想的な雰囲気を演出します。

処理フロー

  1. 入力画像から輝度（ルミナンス）を抽出
  2. 高輝度領域にガウシアンフィルタを適用
  3. 元画像とブレンド

パラメータ

float bloomIntensity

ブルームの強度（デフォルト: 1.0f）

主なSetter（具象クラス GaussianBloom）

void SetBloomIntensity(float) / SetKernelSize(int) / SetSigma(float) / SetThreshold(float)

ブルーム強度・カーネルサイズ・シグマ・閾値を調整します。GetOption() でオプション構造体にも直接アクセスできます。

使用例

// Canvasに追加し、具象クラスへキャストしてパラメータ調整
auto* bloom = static_cast<GaussianBloom*>(
    canvas->GetPostEffectExecutor().AddEffect(PostEffectClassName::GaussianBloom)
);
bloom->Enable(true);
bloom->SetBloomIntensity(1.5f);          // 強度を1.5倍に
// もしくは bloom->GetOption().bloomIntensity = 1.5f;

用途

  • 光源の発光表現
  • 魔法エフェクトの強調
  • 金属や水面の反射の強調
  • 夢幻的な雰囲気の演出

GaussianFilter / SeparatedGaussianFilter（ガウシアンぼかし）

画像をぼかすエフェクト。SeparatedGaussianFilterは水平・垂直方向に分離して処理することで高速化を実現。

特徴

  • 自然で滑らかなぼかし効果
  • 分離処理による高速化
  • カーネルサイズの調整が可能

用途

  • 被写界深度（DOF）の実装
  • ブルームエフェクトの中間処理
  • ソフトフォーカス効果
  • モーションブラーの基礎

DepthBasedOutline（深度ベースアウトライン）

深度バッファを利用してエッジを検出し、アウトライン（輪郭線）を描画するエフェクト。

特徴

  • 深度の変化が大きい部分を検出
  • オブジェクトの輪郭を強調
  • トゥーンシェーディングとの相性が良い

用途

  • セルシェーディング（トゥーンレンダリング）
  • オブジェクトの視認性向上
  • アニメ調の表現

PrewittOutline（プレウィットアウトライン）

プレウィットオペレータを使用したエッジ検出アルゴリズム。色の変化からエッジを検出します。

特徴

  • 色情報ベースのエッジ検出
  • 深度バッファ不要
  • テクスチャの境界も検出

用途

  • スケッチ風の表現
  • イラスト調の輪郭線
  • 画像解析的な表現

RadialBlur（放射ブラー）

指定した中心点から放射状にぼかすエフェクト。スピード感や衝撃を表現できます。

パラメータ

Vector2 center

ブラーの中心位置（0.0～1.0の正規化座標、デフォルト: (0.5, 0.5)）

int samples

サンプル数（デフォルト: 16）。多いほど滑らかだが重くなる。

float blurWidth

ブラー幅（0.0～1.0、デフォルト: 0.01f）

使用例

auto* radialBlur = static_cast<RadialBlur*>(
    canvas->GetPostEffectExecutor().AddEffect(PostEffectClassName::RadialBlur)
);
radialBlur->Enable(true);
radialBlur->GetOption().center = Vector2(0.5f, 0.5f); // 画面中央
radialBlur->SetSamples(24);      // サンプル数を増やして滑らかに
radialBlur->SetBlurWidth(0.02f); // ブラー幅を設定

用途

  • 高速移動の表現
  • 爆発やインパクトの演出
  • 集中線効果
  • ワープ/テレポート演出

Vignette（ビネット）

画面の周辺を暗くする（または特定色で染める）エフェクト。視線誘導や雰囲気作りに有効です。

⚠️ Vignette は実装済みですが、現在 PostEffectClassName に登録されていません。そのため AddEffect() では追加できません（利用するには列挙型とファクトリへの登録が必要です）。以下は実装クラスが公開しているパラメータです。

パラメータ（VignetteOption）

Vector3 color

ビネットの色

float scale

ビネットのスケール（範囲）

float power

ビネットの強度（パワー）

int enableMultiply

乗算モードの有効/無効

主なSetter（具象クラス Vignette）

void SetScale(float) / SetPower(float)

スケール・強度を設定します。色などは GetOption() で VignetteOption に直接アクセスして変更します。

用途

  • 視線の中心への誘導
  • 没入感の向上
  • ダメージ表現（赤いビネット）
  • ホラー演出（暗いビネット）
  • 回想シーン（セピア調ビネット）

Grayscale（グレースケール）

画像をモノクロ（白黒）に変換するエフェクト。

用途

  • 回想シーンの演出
  • ゲームオーバー時の演出
  • 時間停止の表現
  • 古い写真風の表現

Dissolve（ディゾルブ）

ノイズテクスチャを使用して画像を溶解させるエフェクト。フェードとは異なる独特の遷移を実現します。

⚠️ Dissolve は実装済みですが、現在 PostEffectClassName に登録されていません。そのため AddEffect() では追加できません。

特徴

  • ノイズテクスチャベースの溶解パターン
  • 閾値による溶解度の制御
  • エッジカラーの設定が可能

用途

  • シーントランジション
  • オブジェクトの出現/消滅演出
  • 魔法的な消失効果
  • テレポート演出

RandomFilter（ランダムフィルタ）

ランダムノイズを画像に適用するエフェクト。

用途

  • フィルムグレイン効果
  • グリッチ演出
  • 古いテレビ風の表現
  • ホラー演出

LuminanceOutput（輝度出力）

画像から輝度情報を抽出して出力するエフェクト。主にブルームエフェクトの中間処理として使用されます。

特徴

  • RGB値から輝度を計算
  • 閾値による高輝度領域の抽出
  • 他のエフェクトのパイプライン要素として機能

BoxFilter（ボックスフィルタ）

シンプルな平均化フィルタ。周囲のピクセルの平均を取ってぼかしを適用します。

特徴

  • 高速な処理
  • 単純な平均化
  • ガウシアンフィルタより軽量

用途

  • 簡易的なぼかし効果
  • ダウンサンプリング
  • ノイズ除去

Scanline（走査線）

走査線状のラインを重ねるエフェクト。ブラウン管風・レトロな表現に使用します。

用途

  • レトロゲーム風の演出
  • CRTモニター風の表現
  • グリッチ・故障表現

Mosaic（モザイク）

画像をブロック状に量子化してモザイク化するエフェクト。

用途

  • 検閲・伏せ字表現
  • ピクセルアート風の演出
  • ダメージ・ノイズ表現

ChromaticAberration（色収差）

RGBチャンネルをずらして色収差（にじみ）を表現するエフェクト。

用途

  • 衝撃・ダメージ表現
  • レンズ的なリアリティの付与
  • 幻覚・酩酊の演出

Posterize（ポスタリゼーション）

階調数を減らして色を段階化するエフェクト。

用途

  • イラスト・ポスター調の表現
  • トゥーン調の色数削減
  • レトロな色表現

カスタムエフェクトの作成

IPostEffectインターフェースを実装することで、独自のポストエフェクトを作成できます。

実装手順

  1. IPostEffectを継承したクラスを作成
  2. 必要なシェーダーファイル（.hlsl）を作成
  3. パイプラインステートオブジェクトの作成
  4. リソース（テクスチャ、バッファ）の作成
  5. Apply()メソッドでGPU命令を記録

基本的な構造

class CustomEffect : public IPostEffect
{
public:
    void Initialize(const PostEffectInitParams& desc) override {
        // DirectX12オブジェクトの取得
        // パイプラインの作成
        // リソースの確保
    }
    
    void Apply() override {
        // コマンドリストに描画命令を記録
        // ディスパッチ（コンピュートシェーダー）
        // または描画（ピクセルシェーダー）
    }
    
    // その他の必須メソッドを実装
};

サンプルコード

※ 以下の例では、シーンやオブジェクトが保持している Canvas（canvas）に対してエフェクトを追加します。追加したエフェクトのポインタはメンバに保持しておくと、後から有効/無効やパラメータを切り替えられます。

シンプルな使用例

// 初期化時に、Canvasにブルームを追加して有効化する
void MyScene::Initialize()
{
    IPostEffect* bloom = canvas_->GetPostEffectExecutor().AddEffect(
        PostEffectClassName::GaussianBloom
    );
    bloom->Enable(true);
}

動的なパラメータ変更

// 初期化時に追加し、ポインタを保持しておく
// GaussianBloom* pBloom_;
void MyScene::Initialize()
{
    pBloom_ = static_cast<GaussianBloom*>(
        canvas_->GetPostEffectExecutor().AddEffect(PostEffectClassName::GaussianBloom)
    );
}

void MyScene::Update()
{
    // プレイヤーのHPが低いほどブルームを強くする
    float hpRatio = player->GetHP() / player->GetMaxHP();
    pBloom_->Enable(hpRatio < 0.3f);
    pBloom_->SetBloomIntensity(1.0f + 3.0f * (1.0f - hpRatio));
}

スローモーション演出

// 初期化時に追加してポインタを保持:
//   RadialBlur* pRadialBlur_;  Grayscale* pGrayscale_;
void GameScene::ActivateSlowMotion()
{
    pDeltaTimeManager_->SetTimeScale(0.3f);

    // ラジアルブラーで視覚効果を追加
    pRadialBlur_->Enable(true);
    pRadialBlur_->SetBlurWidth(0.015f);
    pRadialBlur_->SetSamples(20);

    // グレースケールで色彩を抑える
    pGrayscale_->Enable(true);
}

void GameScene::DeactivateSlowMotion()
{
    pDeltaTimeManager_->SetTimeScale(1.0f);
    pRadialBlur_->Enable(false);
    pGrayscale_->Enable(false);
}

エフェクトの組み合わせ

// 幻想的なシーンの演出（初期化時に追加）
void CreateDreamyScene(Canvas* canvas)
{
    auto& executor = canvas->GetPostEffectExecutor();

    // ブルームで発光効果
    auto* bloom = static_cast<GaussianBloom*>(
        executor.AddEffect(PostEffectClassName::GaussianBloom)
    );
    bloom->Enable(true);
    bloom->SetBloomIntensity(2.0f); // 強めのブルーム

    // 軽いガウシアンブラーでソフトフォーカス
    executor.AddEffect(PostEffectClassName::SeparatedGaussianFilter)->Enable(true);

    // 色収差でにじみを加える
    executor.AddEffect(PostEffectClassName::ChromaticAberration)->Enable(true);
}
