概要

ポストエフェクトは、レンダリング済みの画像に対して適用される画面全体のエフェクトです。NimaEngineでは、複数のポストエフェクトを組み合わせて使用できます。

主な特徴

  • DirectX12のコンピュートシェーダーを活用した高速処理
  • 複数のエフェクトをチェーン可能
  • リアルタイムでのパラメータ調整
  • リソース状態の自動管理
  • ウィンドウリサイズへの自動対応

処理フロー

シーン描画 → PostEffect 1 → PostEffect 2 → ... → 最終出力

IPostEffect インターフェース

すべてのポストエフェクトはIPostEffectインターフェースを実装しています。

主要メソッド

void Initialize(const PostEffectInitParams& desc)

エフェクトを初期化し、必要なリソースを確保します。

void Finalize()

リソースを解放します。

void Enable(bool flag)

エフェクトの有効/無効を設定します。

bool Enabled() const

エフェクトが有効かどうかを返します。

void Apply()

エフェクトを適用します。コマンドリストにGPU命令を記録します。

void Setting()

描画のための設定を行います。ディスクリプタやリソースの準備を実施します。

void SetInputTextureHandle(D3D12_GPU_DESCRIPTOR_HANDLE gpuHandle)

入力テクスチャのGPUハンドルを設定します。

D3D12_GPU_DESCRIPTOR_HANDLE GetOutputTextureHandle() const

出力テクスチャのGPUハンドルを取得します。

DX12Resource* GetOutputResource() const

適用後のリソースを取得します。

基本的な使い方

1. エフェクトの取得と有効化

// Viewportから特定のポストエフェクトを取得
auto bloom = pViewport_->GetPostEffect<GaussianBloom>();

// エフェクトを有効化
if (bloom) {
    bloom->Enable(true);
}

2. パラメータの調整

// ブルームの強度を調整
auto& bloomOption = bloom->GetOption();
// オプション構造体の値を変更（エフェクトにより異なる）

// または専用のSetterメソッドを使用
auto vignette = pViewport_->GetPostEffect<Vignette>();
if (vignette) {
    vignette->SetScale(0.8f);
    vignette->SetPower(2.0f);
}

3. 複数のエフェクトの組み合わせ

// 複数のエフェクトを有効化
pViewport_->GetPostEffect<GaussianBloom>()->Enable(true);
pViewport_->GetPostEffect<Vignette>()->Enable(true);
pViewport_->GetPostEffect<DepthBasedOutline>()->Enable(true);

// エフェクトは登録順に適用されます

利用可能なエフェクト

GaussianBloom（ガウシアンブルーム）

明るい領域を発光させるエフェクト。光源や反射を強調し、幻想的な雰囲気を演出します。

処理フロー

  1. 入力画像から輝度（ルミナンス）を抽出
  2. 高輝度領域にガウシアンフィルタを適用
  3. 元画像とブレンド

パラメータ

float bloomIntensity

ブルームの強度（デフォルト: 1.0f）

使用例

auto bloom = pViewport_->GetPostEffect<GaussianBloom>();
if (bloom) {
    bloom->Enable(true);
    auto& option = bloom->GetOption();
    option.bloomIntensity = 1.5f; // 強度を1.5倍に
}

用途

  • 光源の発光表現
  • 魔法エフェクトの強調
  • 金属や水面の反射の強調
  • 夢幻的な雰囲気の演出

GaussianFilter / SeparatedGaussianFilter（ガウシアンぼかし）

画像をぼかすエフェクト。SeparatedGaussianFilterは水平・垂直方向に分離して処理することで高速化を実現。

特徴

  • 自然で滑らかなぼかし効果
  • 分離処理による高速化
  • カーネルサイズの調整が可能

用途

  • 被写界深度（DOF）の実装
  • ブルームエフェクトの中間処理
  • ソフトフォーカス効果
  • モーションブラーの基礎

DepthBasedOutline（深度ベースアウトライン）

深度バッファを利用してエッジを検出し、アウトライン（輪郭線）を描画するエフェクト。

特徴

  • 深度の変化が大きい部分を検出
  • オブジェクトの輪郭を強調
  • トゥーンシェーディングとの相性が良い

用途

  • セルシェーディング（トゥーンレンダリング）
  • オブジェクトの視認性向上
  • アニメ調の表現

PrewittOutline（プレウィットアウトライン）

プレウィットオペレータを使用したエッジ検出アルゴリズム。色の変化からエッジを検出します。

特徴

  • 色情報ベースのエッジ検出
  • 深度バッファ不要
  • テクスチャの境界も検出

用途

  • スケッチ風の表現
  • イラスト調の輪郭線
  • 画像解析的な表現

RadialBlur（放射ブラー）

指定した中心点から放射状にぼかすエフェクト。スピード感や衝撃を表現できます。

パラメータ

Vector2 center

ブラーの中心位置（0.0～1.0の正規化座標、デフォルト: (0.5, 0.5)）

int samples

サンプル数（デフォルト: 16）。多いほど滑らかだが重くなる。

float blurWidth

ブラー幅（0.0～1.0、デフォルト: 0.01f）

使用例

auto radialBlur = pViewport_->GetPostEffect<RadialBlur>();
if (radialBlur) {
    radialBlur->Enable(true);
    radialBlur->SetCenter(Vector2(0.5f, 0.5f)); // 画面中央
    radialBlur->SetSamples(24); // サンプル数を増やして滑らかに
    radialBlur->SetBlurWidth(0.02f); // ブラー幅を設定
}

用途

  • 高速移動の表現
  • 爆発やインパクトの演出
  • 集中線効果
  • ワープ/テレポート演出

Vignette（ビネット）

画面の周辺を暗くする（または特定色で染める）エフェクト。視線誘導や雰囲気作りに有効です。

パラメータ

Vector3 color

ビネットの色

float scale

ビネットのスケール（範囲）

float power

ビネットの強度（パワー）

int enableMultiply

乗算モードの有効/無効

使用例

auto vignette = pViewport_->GetPostEffect<Vignette>();
if (vignette) {
                            vignette->Enable(true);
    vignette->SetScale(0.8f); // スケールを設定
    vignette->SetPower(2.0f); // 強度を設定
    
    // オプションで色も調整可能
    auto& option = vignette->GetOption();
    option.color = Vector3(0.0f, 0.0f, 0.0f); // 黒
}

用途

  • 視線の中心への誘導
  • 没入感の向上
  • ダメージ表現（赤いビネット）
  • ホラー演出（暗いビネット）
  • 回想シーン（セピア調ビネット）

Grayscale（グレースケール）

画像をモノクロ（白黒）に変換するエフェクト。

用途

  • 回想シーンの演出
  • ゲームオーバー時の演出
  • 時間停止の表現
  • 古い写真風の表現

Dissolve（ディゾルブ）

ノイズテクスチャを使用して画像を溶解させるエフェクト。フェードとは異なる独特の遷移を実現します。

特徴

  • ノイズテクスチャベースの溶解パターン
  • 閾値による溶解度の制御
  • エッジカラーの設定が可能

用途

  • シーントランジション
  • オブジェクトの出現/消滅演出
  • 魔法的な消失効果
  • テレポート演出

RandomFilter（ランダムフィルタ）

ランダムノイズを画像に適用するエフェクト。

用途

  • フィルムグレイン効果
  • グリッチ演出
  • 古いテレビ風の表現
  • ホラー演出

LuminanceOutput（輝度出力）

画像から輝度情報を抽出して出力するエフェクト。主にブルームエフェクトの中間処理として使用されます。

特徴

  • RGB値から輝度を計算
  • 閾値による高輝度領域の抽出
  • 他のエフェクトのパイプライン要素として機能

BoxFilter（ボックスフィルタ）

シンプルな平均化フィルタ。周囲のピクセルの平均を取ってぼかしを適用します。

特徴

  • 高速な処理
  • 単純な平均化
  • ガウシアンフィルタより軽量

用途

  • 簡易的なぼかし効果
  • ダウンサンプリング
  • ノイズ除去

カスタムエフェクトの作成

IPostEffectインターフェースを実装することで、独自のポストエフェクトを作成できます。

実装手順

  1. IPostEffectを継承したクラスを作成
  2. 必要なシェーダーファイル（.hlsl）を作成
  3. パイプラインステートオブジェクトの作成
  4. リソース（テクスチャ、バッファ）の作成
  5. Apply()メソッドでGPU命令を記録

基本的な構造

class CustomEffect : public IPostEffect
{
public:
    void Initialize(const PostEffectInitParams& desc) override {
        // DirectX12オブジェクトの取得
        // パイプラインの作成
        // リソースの確保
    }
    
    void Apply() override {
        // コマンドリストに描画命令を記録
        // ディスパッチ（コンピュートシェーダー）
        // または描画（ピクセルシェーダー）
    }
    
    // その他の必須メソッドを実装
};

サンプルコード

シンプルな使用例

// 初期化時（NimaFramework::Initialize内など）
// ポストエフェクトは自動的に登録されているため、取得して有効化するだけ

void MyGame::Initialize()
{
    NimaFramework::Initialize();
    
    // ブルームを有効化
    auto bloom = pViewport_->GetPostEffect<GaussianBloom>();
    if (bloom) {
        bloom->Enable(true);
    }
}

動的なパラメータ変更

void MyGame::Update()
{
    NimaFramework::Update();
    
    // プレイヤーのHP が低い時にビネットを強くする
    auto vignette = pViewport_->GetPostEffect<Vignette>();
    if (vignette) {
        float hpRatio = player->GetHP() / player->GetMaxHP();
        
        if (hpRatio < 0.3f) {
            vignette->Enable(true);
            vignette->SetPower(3.0f * (1.0f - hpRatio)); // HPが低いほど強く
            
            auto& option = vignette->GetOption();
            option.color = Vector3(1.0f, 0.0f, 0.0f); // 赤いビネット
        } else {
            vignette->Enable(false);
        }
    }
}

スローモーション演出

void GameScene::ActivateSlowMotion()
{
    // 時間を遅くする
    pDeltaTimeManager_->SetTimeScale(0.3f);
    
    // ラジアルブラーで視覚効果を追加
    auto radialBlur = pViewport_->GetPostEffect<RadialBlur>();
    if (radialBlur) {
        radialBlur->Enable(true);
        radialBlur->SetBlurWidth(0.015f);
        radialBlur->SetSamples(20);
    }
    
    // グレースケールで色彩を抑える
    auto grayscale = pViewport_->GetPostEffect<Grayscale>();
    if (grayscale) {
        grayscale->Enable(true);
    }
}

void GameScene::DeactivateSlowMotion()
{
    pDeltaTimeManager_->SetTimeScale(1.0f);
    
    auto radialBlur = pViewport_->GetPostEffect<RadialBlur>();
    if (radialBlur) radialBlur->Enable(false);
    
    auto grayscale = pViewport_->GetPostEffect<Grayscale>();
    if (grayscale) grayscale->Enable(false);
}

エフェクトの組み合わせ

// 幻想的なシーンの演出
void CreateDreamyScene()
{
    // ブルームで発光効果
    auto bloom = pViewport_->GetPostEffect<GaussianBloom>();
    if (bloom) {
        bloom->Enable(true);
        auto& option = bloom->GetOption();
        option.bloomIntensity = 2.0f; // 強めのブルーム
    }
    
    // ビネットで周辺を暗く
    auto vignette = pViewport_->GetPostEffect<Vignette>();
    if (vignette) {
        vignette->Enable(true);
        vignette->SetScale(0.7f);
        vignette->SetPower(1.5f);
    }
    
    // 軽いガウシアンブラーでソフトフォーカス
    auto blur = pViewport_->GetPostEffect<SeparatedGaussianFilter>();
    if (blur) {
        blur->Enable(true);
        // ブラーの強さを調整（実装依存）
    }
}
