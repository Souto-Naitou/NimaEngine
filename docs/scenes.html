概要

NimaEngineのシーンシステムは、ゲームの各場面（タイトル、ゲーム、リザルトなど）を管理します。

主な特徴

  • シーンの自動的なライフサイクル管理
  • シーン間のデータ受け渡し（SceneArgs）
  • トランジションエフェクト付きシーン遷移
  • ファクトリパターンによる柔軟なシーン生成
  • レイヤーシステムとの統合
  • 初期引数の一括設定機能

典型的なシーン構成

  • TitleScene - タイトル画面
  • LoadScene - ロード画面
  • GameScene - ゲームプレイ
  • ClearScene - ゲームクリア
  • GameOverScene - ゲームオーバー

アーキテクチャ

クラス構成

SceneManager

シングルトンクラス。シーンの遷移、ライフサイクル管理を担当します。

SceneBase

すべてのシーンが継承する基底クラス。Initialize, Update, Draw等を実装します。

ISceneFactory

シーン生成のインターフェース。プロジェクトごとに実装します。

ISceneArgs

シーン間でデータを受け渡すための引数インターフェース。

TransBase

シーン遷移エフェクトの基底クラス。TransShutter等が実装します。

シーン遷移のフロー

現在のシーン
    ↓
SceneManager::ReserveScene("NextScene")
    ↓（次フレーム）
[Transition Out]（現在のシーンがフェードアウト）
    ↓
現在のシーン::Finalize()
    ↓
ISceneFactory::Create("NextScene", args)
    ↓
新しいシーン::Initialize()
    ↓
[Transition In]（新しいシーンがフェードイン）
    ↓
新しいシーン::Update(), Draw()

SceneManager

シーン全体を管理するシングルトンクラス。

インスタンスの取得

auto sceneManager = SceneManager::GetInstance();

主要メソッド

void Initialize()

SceneManagerを初期化します。フレームワークによって自動的に呼ばれます。

void Update()

現在のシーンを更新します。遷移予約がある場合は実行します。

void SceneDraw()

現在のシーンを描画します。

void ReserveScene(const std::string& sceneName)

次フレームで遷移するシーン名を予約します。

void ReserveScene(const std::string& sceneName, std::unique_ptr<TransBase>&& transition)

トランジションエフェクト付きでシーンを予約します。

void SetSceneFactory(ISceneFactory* pSceneFactory)

シーン生成に使用するファクトリを設定します。

void SetSceneArgs(std::unique_ptr<ISceneArgs> pSceneArgs)

次回シーン生成に渡す引数を設定します。

SceneManager& AddInitialArg(const std::string& key, const std::any& value)

すべてのシーンに渡す初期引数を追加します。

使用例

auto sceneManager = SceneManager::GetInstance();

// 通常のシーン遷移
sceneManager->ReserveScene("GameScene");

// トランジション付き遷移
auto transition = std::make_unique<TransShutter>();
sceneManager->ReserveScene("TitleScene", std::move(transition));

SceneBase

すべてのシーンが継承する基底クラス。

コンストラクタ

SceneBase(ISceneArgs* pArgs)

純粋仮想関数（必須実装）

virtual void Initialize() = 0

シーンの初期化処理。リソースの読み込み、オブジェクトの生成などを行います。

virtual void Finalize() = 0

シーンの終了処理。リソースの解放を行います。

virtual void Update() = 0

シーンの更新処理。毎フレーム呼ばれます。

virtual void Draw() = 0

シーンの描画処理。毎フレーム呼ばれます。

仮想関数（任意でオーバーライド）

virtual void OnSceneChangeReserved()

シーン変更が予約されたときに呼ばれるコールバックです。

保護メンバ変数

ISceneArgs* pArgs_

シーンに渡された引数。エンジンの各システムへのポインタが含まれます。

OrderedCanvasLayer* pLayer_

レイヤーシステムへのポインタ。

シーン実装の基本構造

class GameScene : public SceneBase
{
public:
    GameScene(ISceneArgs* pArgs) : SceneBase(pArgs) {}
    ~GameScene() override {}
    
    void Initialize() override;
    void Finalize() override;
    void Update() override;
    void Draw() override;

private:
    // シーン固有のメンバ変数
};

SceneArgs

概要

ISceneArgsは、シーン間でデータを受け渡すためのインターフェースです。

主な用途

  • エンジンシステムへのポインタ取得（DirectX12、Input、AudioManagerなど）
  • 前のシーンからのデータ受け渡し（スコア、設定など）

引数の取得

void GameScene::Initialize()
{
    // pArgs_からシステムポインタを取得
    auto pDx12 = std::any_cast<DirectX12*>(pArgs_->Get("DirectX12"));
    auto pInput = std::any_cast<Input*>(pArgs_->Get("Input"));
    auto pCubemapSystem = std::any_cast<CubemapSystem*>(pArgs_->Get("CubemapSystem"));
    
    #ifdef _DEBUG
    auto pImGuiManager = std::any_cast<ImGuiManager*>(pArgs_->Get("ImGuiManager"));
    #endif
}

カスタム引数の設定と取得

// シーンAからシーンBへデータを渡す

// シーンA
void SceneA::TransitionToSceneB()
{
    auto sceneManager = SceneManager::GetInstance();
    
    // カスタム引数を作成（ISceneArgsを実装）
    auto args = std::make_unique<CustomSceneArgs>();
    args->Set("PlayerScore", 12345);
    args->Set("PlayerName", std::string("Hero"));
    
    sceneManager->SetSceneArgs(std::move(args));
    sceneManager->ReserveScene("SceneB");
}

// シーンB
void SceneB::Initialize()
{
    // カスタム引数を取得
    int score = std::any_cast<int>(pArgs_->Get("PlayerScore"));
    std::string name = std::any_cast<std::string>(pArgs_->Get("PlayerName"));
    
    std::cout << name << "'s score: " << score << std::endl;
}

ライフサイクル

シーンのライフサイクル

シーン生成
    ↓
Initialize() - 1回だけ呼ばれる
    ↓
┌─ Update() ─ 毎フレーム呼ばれる
│   ↓
└─ Draw() ─ 毎フレーム呼ばれる
    ↓
（シーン遷移が予約されたら）
    ↓
Finalize() - 1回だけ呼ばれる
    ↓
シーン破棄

各メソッドの役割

Initialize()

  • リソースの読み込み（テクスチャ、モデル、音声）
  • オブジェクトの生成と配置
  • カメラの設定
  • ポストエフェクトの設定
  • Canvasの作成

Update()

  • 入力の処理
  • ゲームロジックの更新
  • オブジェクトの更新
  • カメラの更新
  • シーン遷移の判定

Draw()

  • 3Dオブジェクトの描画
  • スプライトの描画
  • パーティクルの描画
  • UIテキスト・スコアなどの描画
  • ポストエフェクトの適用

Finalize()

  • 作成したオブジェクトの破棄
  • Canvasの解放
  • ポストエフェクトの削除
  • レイヤーからのCanvas削除

シーン遷移

通常のシーン遷移

void TitleScene::Update()
{
    if (Input::GetInstance()->TriggerKey(DIK_SPACE))
    {
        auto sceneManager = SceneManager::GetInstance();
        sceneManager->ReserveScene("GameScene");
    }
}

トランジション付き遷移

シーン遷移時にフェードイン/フェードアウトなどのエフェクトを適用できます。

利用可能なトランジション

  • TransShutter - シャッターエフェクト
  • その他、TransBaseを継承したカスタムトランジション

使用例

void TitleScene::Update()
{
    if (Input::GetInstance()->TriggerKey(DIK_SPACE) && !isChangingScene_)
    {
        // トランジションエフェクトを作成
        auto transition = std::make_unique<TransShutter>();
        
        // トランジション付きで遷移予約
        auto sceneManager = SceneManager::GetInstance();
        sceneManager->ReserveScene("LoadScene", std::move(transition));
        
        isChangingScene_ = true; // 重複防止フラグ
    }
}

基本的な使い方

1. シーンクラスの定義

// GameScene.h
#pragma once
#include <Scene/SceneBase.h>
#include <memory>

class GameScene : public SceneBase
{
public:
    GameScene(ISceneArgs* pArgs);
    ~GameScene() override;
    
    void Initialize() override;
    void Finalize() override;
    void Update() override;
    void Draw() override;

private:
    // メンバ変数
    std::unique_ptr<GameEye> gameEye_;
    std::unique_ptr<Canvas> pCanvas_;
    Input* pInput_ = nullptr;
    SceneManager* pSceneManager_ = nullptr;
};

2. シーンの実装

// GameScene.cpp
#include "GameScene.h"

GameScene::GameScene(ISceneArgs* pArgs)
    : SceneBase(pArgs)
{
}

GameScene::~GameScene()
{
}

void GameScene::Initialize()
{
    // システムポインタの取得
    pInput_ = Input::GetInstance();
    pSceneManager_ = SceneManager::GetInstance();
    auto pDx12 = std::any_cast<DirectX12*>(pArgs_->Get("DirectX12"));
    
    // カメラの初期化
    gameEye_ = std::make_unique<GameEye>();
    gameEye_->SetTranslate(Vector3(0, 10, -30));
    
    // Canvasの初期化
    Canvas::Params params = {};
    params.name = "GameCanvas";
    params.pDx12 = pDx12;
    
    pCanvas_ = std::make_unique<Canvas>();
    pCanvas_->Initialize(params);
    pLayer_->AddCanvas(pCanvas_.get());
}

void GameScene::Finalize()
{
    // Canvasの解放
    pLayer_->RemoveCanvas(pCanvas_.get());
    pCanvas_->Finalize();
}

void GameScene::Update()
{
    // カメラの更新
    gameEye_->Update();
    
    // シーン遷移の判定
    if (pInput_->TriggerKey(DIK_ESCAPE))
    {
        pSceneManager_->ReserveScene("TitleScene");
    }
}

void GameScene::Draw()
{
    // 描画処理（テキスト描画もここで行います）
}

3. SceneFactoryへの登録

// SceneFactory.cpp
std::unique_ptr<SceneBase> SceneFactory::Create(
    const std::string& sceneName,
    ISceneArgs* sceneArgs)
{
    if (sceneName == "TitleScene")
    {
        return std::make_unique<TitleScene>(sceneArgs);
    }
    else if (sceneName == "GameScene")
    {
        return std::make_unique<GameScene>(sceneArgs);
    }
    else if (sceneName == "ClearScene")
    {
        return std::make_unique<ClearScene>(sceneArgs);
    }
    
    return nullptr;
}

サンプルコード

タイトルシーンの実装（Calms参照）

class TitleScene : public SceneBase
{
private:
    std::unique_ptr<GameEye> gameEye_;
    std::unique_ptr<Canvas> pCanvasBack_;
    std::unique_ptr<Canvas> pCanvasSprite_;
    std::unique_ptr<TransShutter> pTransShutter_;
    Input* pInput_ = nullptr;
    SceneManager* pSceneManager_ = nullptr;
    Audio* pSoundStartButton_ = nullptr;
    bool isChangingScene_ = false;
    
public:
    void Initialize() override
    {
        // インスタンスの取得
        pInput_ = Input::GetInstance();
        pSceneManager_ = SceneManager::GetInstance();
        auto pDx12 = std::any_cast<DirectX12*>(pArgs_->Get("DirectX12"));
        auto pCubemapSystem = std::any_cast<CubemapSystem*>(pArgs_->Get("CubemapSystem"));
        
        // Canvasの初期化
        Canvas::Params params = {};
        params.name = "TitleCanvas";
        params.pDx12 = pDx12;
        params.pCubemapSystem = pCubemapSystem;
        
        pCanvasBack_ = std::make_unique<Canvas>();
        pCanvasBack_->Initialize(params);
        pLayer_->AddCanvas(pCanvasBack_.get());
        
        // ゲームアイの初期化
        gameEye_ = std::make_unique<GameEye>();
        gameEye_->SetTranslate(Vector3(0, 0, -10));

        // ポストエフェクトの設定
        auto bloom = pCanvasBack_->GetPostEffectExecutor().AddEffect(
            PostEffectClassName::GaussianBloom
        );
        
        // 効果音の設定
        auto audioManager = AudioManager::GetInstance();
        pSoundStartButton_ = audioManager->GetNewAudio("Effect", "button.wav");
        pSoundStartButton_->SetVolume(0.1f);
    }
    
    void Finalize() override
    {
        pLayer_->RemoveCanvas(pCanvasBack_.get());
        pCanvasBack_->Finalize();
    }
    
    void Update() override
    {
        // カメラの回転
        Vector3 eyeRotate = gameEye_->GetTransform().rotate;
        eyeRotate.y += 0.001f;
        gameEye_->SetRotate(eyeRotate);
        gameEye_->Update();
        
        // スペースキーでゲーム開始
        if (pInput_->TriggerKey(DIK_SPACE) && !isChangingScene_)
        {
            pSoundStartButton_->Play();
            
            // トランジション付きでロードシーンへ遷移
            pTransShutter_ = std::make_unique<TransShutter>();
            pSceneManager_->ReserveScene("LoadScene", std::move(pTransShutter_));
            
            isChangingScene_ = true;
        }
    }
    
    void Draw() override
    {
        // 描画処理（テキスト描画もここで行います）
    }
};

ゲームシーンからクリアシーンへの遷移

class GameScene : public SceneBase
{
private:
    bool isGameClear_ = false;
    
public:
    void Update() override
    {
        // ゲームロジック...
        
        // クリア条件をチェック
        if (CheckClearCondition())
        {
            isGameClear_ = true;
        }
        
        // クリア時の処理
        if (isGameClear_)
        {
            // スコアを次のシーンに渡す
            auto args = std::make_unique<CustomSceneArgs>();
            args->Set("FinalScore", currentScore_);
            args->Set("ClearTime", clearTime_);
            
            auto sceneManager = SceneManager::GetInstance();
            sceneManager->SetSceneArgs(std::move(args));
            
            // トランジション付きで遷移
            auto transition = std::make_unique<TransShutter>();
            sceneManager->ReserveScene("ClearScene", std::move(transition));
        }
    }
};

class LoadScene : public SceneBase
{
private:
    bool isLoadingComplete_ = false;
    float loadingProgress_ = 0.0f;
    
public:
    void Initialize() override
    {
        // ローディング画面のUIを表示
    }
    
    void Update() override
    {
        // リソースの非同期ロード（疑似コード）

        {
            loadingProgress_ += 0.01f;

                isLoadingComplete_ = true;
            }

        {
            // ロード完了後、ゲームシーンへ
            SceneManager::GetInstance()->ReserveScene("GameScene");
        }
    }
    
    void Draw() override
    {
        // ローディングバーの描画
        int progress = static_cast<int>(loadingProgress_ * 100);
        // DrawText(...);
    }
};

Tips & ベストプラクティス

1. シーン遷移の重複防止

連続でシーン遷移が呼ばれないようフラグで制御しましょう。

bool isChangingScene_ = false;

if (input && !isChangingScene_)
{
    sceneManager->ReserveScene("NextScene");
    isChangingScene_ = true;
}

2. Finalizeでのリソース解放

Initialize()で作成したものは、必ずFinalize()で解放してください。

3. pArgs_の活用

エンジンのシステムポインタはpArgs_から取得できます。

4. Canvasの管理

// Initialize()
pLayer_->AddCanvas(pCanvas_.get());

// Finalize()
pLayer_->RemoveCanvas(pCanvas_.get());
pCanvas_->Finalize();

5. トランジションの使い分け

  • 重要なシーン遷移（タイトル→ゲーム）: トランジション付き
  • 軽微な遷移（設定画面など）: トランジションなし

6. シーン間のデータ受け渡し

大きなデータはシングルトンやグローバルストレージで管理し、SceneArgsは軽量なデータのみに使用しましょう。

7. デバッグ用のシーン直行

#ifdef _DEBUG
if (Input::GetInstance()->TriggerKey(DIK_F1))
{
    sceneManager->ReserveScene("TestScene");
}
#endif

8. ライフサイクルの理解

Initialize()は1回、Update()とDraw()は毎フレーム、Finalize()は1回呼ばれることを意識してください。
